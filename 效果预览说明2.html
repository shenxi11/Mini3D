本轮复刻重点

不是：给旧 Dock 设置深色样式，把控制台换成假时间轴。

而是：工作区与编辑模式分离；T 工具条与 N 侧栏分离；右上 Outliner 与右下属性编辑器分离；F3 搜索、Q 收藏与 F9 调参使用同一操作注册表；模态状态栏解释当前操作；原始网格与修改器求值结果同时可读。

新尺寸、颜色 token 是 Mini3D 的建议规范，不是对旧截图的精确取样。真实一致性需要后续在固定分辨率与 UI Scale 下，用同一操作配方逐项截图验收。
