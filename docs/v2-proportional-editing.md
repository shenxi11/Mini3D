# 比例编辑（P1-PROP）

Edit 模式下按 `O` 开关比例编辑，或使用“编辑 → 组件变换 → 比例编辑”。选中的源顶点始终完整变换，周围顶点按 Smooth 衰减一起移动、旋转或缩放。

## 操作

1. 选择点、边或面；边/面以其去重源顶点作为驱动点。
2. 开启比例编辑，执行 `G/R/S`。视口显示驱动点的世界半径圈，状态提示当前半径。
3. 滚轮调整半径，不缩放世界相机；模态中 `O` 可切换普通变换与比例变换，均从启动前源快照重算。
4. 左键/Enter 确认只产生一次历史；Esc 恢复全部受影响位置、属性和选区。

“仅连通”默认开启，只影响与任一驱动点通过源边连接的连通片。关闭后可影响同一个编辑对象的其他连通片；不会编辑其他对象。隐藏顶点不参与影响。

## 数学与组合边界

- 使用最近驱动点的世界欧氏距离，非测地距离；非均匀对象变换下仍按世界单位计算半径。
- 距离比例 `t=d/r` 的权重为 `1-3t²+2t³`，半径外权重为零。只提供 Smooth，不提供其他衰减类型。
- 权重作用于 G/R/S 产生的世界位移，再回到对象局部坐标；移动滚轮不累加上一帧位置。
- 多驱动点分别显示半径圈；关闭叠加或查看场景摄像机时不显示圈。
- Mirror Clipping 包含本次受影响的非选中中心边界顶点。失败预览不捕获新中心约束。
- 比例编辑顶点吸附排除整个被编辑源对象，避免把正在变动的非选中点当作吸附目标；其他可见对象仍可作为目标。
- 仅普通组件 G/R/S 使用比例编辑，挤出、内插、环切与对象变换不受此开关影响。
- 开关、Connected 与半径是窗口工作偏好，不写场景文件、不单独增加历史。
