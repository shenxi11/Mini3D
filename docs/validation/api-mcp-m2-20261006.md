## 独立审查与回归

两个独立 Sol 审查发现的网格问题已有有效 red 和 green：

- 细分预算曾把面角数量误作几何点。90 个独立 Cube、二级细分和单面内插的最终几何为 8,884 点、8,704 面、34,816 角，均在限额内；现按源唯一边递推 V/E/F/C，并核验实际最终容量。
- 零位移挤出曾跳过连通性/边界检查。不相邻面或整壳仍须先验证区域，不能以 no_change 绕过拓扑约束。

修复前 `[mesh-subdivision-budget],[mesh-zero-region]` 为 2 用例 / 37 断言，其中 3 失败、程序退出 42。`verify-mesh-red.ps1` 自身退出 0 只代表预期 red 确实发生，不是测试通过；原日志 `tests-mesh-red.log` 保留。上述回归已纳入本次绿色网格集合。未参与实现的 Sol 对最终递推和零位移检查位置进行只读关闭复核。

## 限制与后续

沿用现有内核：内插只支持共面凸面和正局部厚度；不增加新建模算法。源和最终求值各自受合同限额约束，GPU 拆点与候选副本另计内存。拒绝旧文档、旧网格绑定和旧源版本；客户端必须用结果中的稳定 ID 和最新版本继续。
