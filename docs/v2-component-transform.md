# 组件移动、旋转、缩放（EDIT-03）

## 使用方式

选择可编辑网格并进入 Edit，选择点、边或面，再启动组件变换。对象模式的操作仍只作用于
对象 TRS；Edit 的入口仅改变去重后的所选源顶点，不移动对象原点、不影响其他实例。
当前可直接进入 Edit 的对象仍为原生 Cube 和已有可编辑网格；球体、平面、静态 glTF
转换还未完成。这里不以 G/R/S 可用宣称拓扑工具、Mirror、F9 或二期整体完成。

| 操作 | Blender 风格 | 两套键位都可用的入口 |
| --- | --- | --- |
| 移动组件 | G | 编辑 → 组件变换 → 移动组件；F3 / Q |
| 旋转组件 | R | 编辑 → 组件变换 → 旋转组件；F3 / Q |
| 缩放组件 | S | 编辑 → 组件变换 → 缩放组件；F3 / Q |
| 轴约束 | X / Y / Z；同轴再按切换全局 / 局部 | 模态中的同样按键 |
| 排轴平面 | Shift+X / Y / Z（移动与缩放） | 模态中的同样按键 |
| 精细 / 临时反转吸附 | Shift / Ctrl | 相同 |
| 确认 / 取消 | Enter 或视口内左键 / Esc 或右键 | 相同 |

例如 `G X .25` 沿全局 X 移动 0.25；`R Y 15` 绕选择中心旋转 15 度；
`S Shift+Z .8` 仅缩放 X/Y 两轴。保留项目 Y-up，不切换为 Blender 原生 Z-up。
无约束旋转绕观察方向；无约束数值移动沿鼠标给定方向，无方向时取当前空间的 X 轴。
移动轴正对视线/约束平面近平行导致鼠标解算不适用时，提示使用数值或调整视角。
步进沿用移动 0.5、旋转 15°、缩放 0.1；Ctrl 对当前偏好取反，精确数值不被步进改写。

组件 R/S 默认使用所选顶点去重后的世界质心；单点绕自身旋转/缩放是无变化操作。
PIVOT-01已接入活动元素/游标枢轴，见[变换枢轴](v2-pivot.md)；顶点吸附仍待SNAP-01。局部方向沿对象与祖先的旋转
组合，忽略缩放造成的轴长或镜像符号；世界增量通过完整逆世界矩阵回写顶点，支持父节点
非均匀和负缩放。组件可直接表达非 TRS 变形；对象世界旋转仍拒绝不可表达剪切，
对象缩放则按[保留旋转的缩放规则](rotated-object-scaling.md)换算局部分量，不改写顶点。

Legacy 的 W/E/R 仍只开关原对象手柄，Edit 中禁用；组件操作可由菜单、F3、Q 启动。
G/R/S 的快捷键标签随模式切换，只显示在当前模式对应动作，不出现同时触发两个动作。
Registry 在 EDIT-03 新增 `mesh.translate` / `mesh.rotate` / `mesh.scale`，当时总计 43 项；
MODEL-01 加入 [区域挤出](v2-extrude-region.md) 后为 44 项，HISTORY-02 增加调整上一步后为 45 项。
MODEL-02 增加 [单面内插](v2-inset-face.md) 后为 46 项。
与对象操作使用不同 ID，但共用数值、鼠标、轴约束和精细输入逻辑。

## 预览、确认与取消

- 开始时冻结 MeshId、evaluationRevision、世界矩阵、稳定选区和 before 内容。
  每帧从 before 重算，边端点与面角只取并集，不因共享顶点被重复移动。
- 候选是独立不可变 CPU 快照。`scene()` 真源、文档 dirty、历史和几何 revision 在预览时
  不变；不向场景树发布重建通知。视口实体、源边/点/面覆盖层和 N 侧栏读取同一候选。
  侧栏提示“尚未写入文档”；关闭 Overlay 仍能看到真实实体变形。
- GPU 上传/替换仅在原 Context 的绘制阶段执行；取消切回原内容并使 GPU 缓存刷新。
  不复制整个 Scene、不重挂 QOpenGLWidget。
- 确认只安装一次 after 并新增一条历史。无变化零历史，不消耗 redo；Undo/Redo 安装
  内容快照，不重新运行变换，Scene 三类 revision 均向前推进。
  当前仍 Edit 同一对象时，一并恢复操作保存的选择域、selectedIds 和 activeId；不会从
  Object 自动进入 Edit，也不会把编辑会话或 Undo 栈写入文件。
- 零缩放、非有限/不可逆增量、浮点溢出或退化/不可三角化候选拒绝。无效预览保留上一有效
  画面用于修正，但不能确认旧候选；错误在状态/HUD 中提示，可退格修正或取消。
- Esc、右键、失焦/失活、视口尺寸变化、鼠标抓取丢失、输入法预编辑、Tab、键位切换、
  相机视角改变，以及选区/域/对象/显隐/数据/文档变化取消旧事务。B 与 G/R/S 不共存。
  文件意图先取消；保存中途预览会写入 before，确认后保存才写入 after。

保持拓扑环、稳定 ID、UV、颜色和面材质；局部变形的受影响面重算法线，整面变换按
逆转置和实际绕序更新硬法线。负缩放允许但不自动反转源环。非共面面按既有简单投影
三角化规则处理；没有全局自相交检测，不能宣称任何变形都无自交。
