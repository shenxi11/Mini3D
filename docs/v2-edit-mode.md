# 单对象编辑与组件选择（EDIT-02 / PICK-01 / EDIT-03 / MODEL-01/02/03/04）

## 已接通的工作流

选择一个可见原生立方体，在视口按 Tab 或使用 Header“模式”菜单进入编辑模式。
首次进入将原生 Cube 转为独立可编辑源网格（8 点、12 边、6 四边面），产生一条
“转为可编辑网格”历史；已有可编辑源不重复转换。退出模式不把它转回静态网格。
当前仍不支持球体、平面、静态 glTF 直接进入 Edit，也不支持多对象同时 Edit。

| --- | --- | --- |
| 对象 / 编辑模式 | Tab，长按不反复切换 | Header 模式菜单 |
| 点 / 边 / 面选择域 | 主键 1 / 2 / 3 | Header 点 / 边 / 面按钮 |

主键与小键盘区分；Legacy 主键 1/3/7 仍控制视图，不改选择域。文本框、数值控件、
输入法预编辑和弹窗保持输入优先级。工作区标签只改布局，不改变当前 Object/Edit。

切换模式先取消未确认的对象模态/手柄预览。Edit 中整对象 G/R/S、手柄、创建/导入、
复制、删除、换父和对象 TRS 属性入口不可执行；底层意图入口也拒绝，不只禁用按钮。
组件 G/R/S 使用独立入口修改源顶点，详见 [组件变换](v2-component-transform.md)；
区域挤出与单面内插已接通，见 [区域挤出](v2-extrude-region.md)、[面内插](v2-inset-face.md)；
环切也已接通，见 [环切](v2-loop-cut.md)；分域删除和单环补面见 [删除与补面](v2-fill-delete.md)。对象名称、持久显隐
与外观入口保留。选中其他对象、编辑对象或祖先隐藏、删除/撤销导致绑定失效时退出 Edit
并清理组件选择；进入实体相机预览也退出 Edit。返回时需显式重新进入。

## 稳定身份、活动项与投影规则

点/面 ID 为 64 位稳定身份，边为排序后的两个端点 ID，绝不是数组下标或渲染拆点索引。
每次只有一个选择域；选中集合与活动项分开。替换或追加一个已有选中项也可更新活动项。
移除/删除活动项后保留仍有效选择，活动项回退到最小稳定 ID；空选择没有活动项。

- 面 → 边/点：取所选多边形的边界/角顶点并集。
- 边 → 点：取所选边的端点并集。
- 点 → 边：只选两端都已选中的源边；点 → 面：只选所有边界顶点已选中的面。
- 边 → 面：必须所有边界边都已选中，不能只因端点并集覆盖面就选中该面。
- 切换域后活动项取结果的最小稳定 ID；不会恢复其他域的隐藏旧选区。

进入 Edit 初始为点域全选；退出/重进重新初始化选区。模式和选择本身不进入 Undo 或
改变已保存状态，首次几何转换例外。N 侧栏显示对象名、域内已选/总数、活动 ID 与局部
坐标：点位置、边中点、面角顶点均值。EDIT-03 中 N 侧栏会读取独立变换候选，并标明
尚未写入文档；Undo/Redo 在仍编辑同一对象时恢复几何与操作选区，不保存编辑会话。
区域挤出保持原面身份指向新顶盖，确认和 Undo/Redo 保留操作的面选区；
内插保留原面身份指向中心面，边框使用新 ID，可接着挤出中心面。
环切预览不改变原选区；覆盖层/N侧栏显示新切线候选，确认切换到新边域并选中切线。
Undo恢复原域/选区，Redo恢复新切线；新边可继续组件G/R/S。
删除清理失效选区，补面后切面域并选中新面；两者 Undo/Redo 恢复对应几何与域/选区。
允许删除全部组件后保留空网格对象，不提供保留散边或溶解删除。

## 可见单击与真实反馈

坐标来自实际 QOpenGLWidget 的逻辑矩形，DPI 变化不把物理像素误当鼠标坐标。
点/边使用 10 逻辑像素命中半径；先屏幕距离、再深度、最后稳定 ID 决定结果。
边投影使用齐次裁剪和线性投影深度；面使用精确三角射线命中并映射回 SourceFaceId。
三角化对角线不可作为边选择。使用场景中可见几何作三角遮挡测试，包含父变换、
负/非均匀缩放和导入材质的单双面规则；对象 AABB 不作为最终组件命中依据。

源边、顶点/面中心、已选面的覆盖层来自同一源网格和选区；活动项为浅色，已选为橙色。
覆盖层默认检查深度，X-Ray 时显示被遮挡组件；不写深度，极小偏移用于避免同面闪烁。选区/几何改变更新 CPU
显示数据并递增显示 revision，GL 上传仅在 paintGL 的 Context 内发生；相机导航不重传
同一缓冲，不重挂 QOpenGLWidget。对象模式保留原包围盒反馈。

PICK-01 已接通 B 框选、X-Ray、独立 Overlay 总开关及跨近/远/侧裁剪面的边段。
框选固定为点投影、边段触碰、面中心规则；可见边使用连续未遮挡区间，不只测中点。
具体操作、取消、显示状态与性能边界见 [组件框选](v2-component-picking.md)。
元素 H/Alt+H 属 VIS-01；这里已验证的是对象/祖先隐藏与几何删除后的 ID 清理。
