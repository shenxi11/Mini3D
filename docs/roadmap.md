# Mini3D Studio V1 路线图

V1 计划周期为 8 周，每周约 7—9 个有效小时。每周只推进一个可演示闭环；卡期时先裁剪
视觉增强，不裁剪 Scene Graph、glTF、Picking、Move Gizmo、保存加载和 Undo。

| --- | --- | --- |

| 第 1 周 | 编辑器壳、OpenGL、Cube、Camera、Grid | 可观察基础物体并安全调整窗口 |

### 汉化边界

- 汉化用户可见文案，不翻译类/函数名、Qt objectName、稳定 ID、资源键、JSON 字段、
  文件扩展名或格式枚举值；不升级场景格式，不改变模型路径或快捷键语义。
- 产品名 Mini3D Studio、Qt/OpenGL、glTF/GLB 等专名，以及 X/Y/Z、RGB 等标准标记可保留；
  对 FOV、TRS 等参数提供中文含义。所有保留项须在实施清单中说明。
- 已保存的实体名称、用户输入、导入模型名称、文件名及路径保持原样，不自动翻译或重命名。
  中文默认名称只影响新建对象；名称显示不应成为内部对象类型或测试定位依据。
- 本应用产生的错误应有中文说明。第三方库、显卡驱动及操作系统的原始诊断允许保留原文，
  配合中文上下文，不机械翻译或删除错误码、路径与底层错误内容。
- Qt 标准对话框的翻译资源须在实施时核实；系统原生对话框受系统语言影响，
  必须在验收中明确实测结果及必要的 Qt 对话框方案，不能仅凭主菜单中文就判定完成。
- 本阶段不重制历史截图、视频或原候选 ZIP；已更新当前用户说明并生成独立验证包，正式候选和演示后续更新。
  不翻译第三方法律文本、不扩大到全仓库源码注释或开发工具汉化。

### 最终验收场景

中文界面下完成“新建 → 创建物体 → 导入模型 → 修改层级/变换 → 调整相机与灯光 →
撤销/重做 → 中文路径保存 → 关闭重开”；另覆盖损坏文件、缺失资源、非法参数、
保存失败和取消退出。旧 version 1/2 场景仍可读取，用户对象名称不变。
检查中文输入时快捷键不抢焦点，翻译占位符/单位正确，100%/200% 缩放和缩小窗口时
关键按钮、三轴字段与预览退出入口可见可操作。汉化期间逐步骤完成实现、验证和日志追加。
