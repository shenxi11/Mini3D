## 实际制作方式与验证

没有使用电脑操控技能、Blender、图像生成器或直接改写工程格式。纯几何脚本只准备点面，全部应用场景创建、集合分配、灯光、视角、保存和重开由官方 SDK 经项目 MCP stdio 工具完成。PNG 为真实 `viewport.capture` 返回的 image 内容，没有另行生成或修图。

已完成：

1. `system.describe` 确认 API 0.1.0 / wire 1、创建/观察/文件能力与实际限额。
2. 纯几何预检确认有限坐标、有效且不重复的面索引、非零面积、共面性、最多双面邻接、共享边相反方向、颜色范围及各请求点面/角点/字节预算。
3. 首次 `file.saveAs` 后完成 `file.save` → `document.open`；逐一 `entity.get` / `mesh.getSummary` 核对 39 个网格的顶点和面数保持不变，实体数保持 41。
4. 重开后捕获七张视图，加此前同一几何的侧面图，共八张 1178 × 736 PNG；每张字节 SHA-256 与 MCP 回执一致。最后恢复主视角再保存，`isModified=false`、`busy=false`。
