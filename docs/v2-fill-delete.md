# 删除组件与补面（MODEL-04）

本项完成点/边/面删除及单个共面边界补面，不扩展源网格结构、不新增场景格式。
仅支持当前可进入 Edit 的单个原生 Cube 或已有可编辑网格。

## 删除：X / Delete

Edit 中选好组件，鼠标位于视口时按 Blender 风格 `X` 或 `Delete`，打开删除菜单。
菜单“编辑 → 组件变换 → 删除组件…”为替代入口；Legacy Edit 同样可用 Delete，
不绑定 X。方向键选项目、Enter 或鼠标点击确认；Esc/点菜单外取消，不改几何或历史。
默认活动菜单项跟随当前选择域。

| 菜单项 | 实际影响 |
| --- | --- |
| 删除点及关联面 | 删除所选顶点关联的完整面，随后清理无面引用顶点 |
| 删除边及关联面 | 删除所选源边的一侧或两侧相邻面；不是溶解边、不是重新拼面 |
| 删除面（保留仍被使用的边界） | 仅删除所选面；其他面仍在使用的边界保留，清理无面引用顶点 |

选不同域的删除项时，按既有规则投影当前选区：面到边/点取边界元素，点/边到面要求
完整覆盖该面边界；没有完整目标时禁用。**选择一个面后选“删除点”会扩大到这些点的
相邻面**，不是“只删当前面”。不保留独立散边或孤立点，不提供 Blender 的 Only Faces、
Dissolve、Only Edges & Faces 等未实现选项。

删除后清理全部孤立顶点和失效选区。若候选导致非流形、多扇顶点等当前不支持的结构，
整次拒绝并显示原因，不偷偷拆点修补。允许删除全部组件，结果是仍在场景树中的空网格对象，
不是删除对象。可撤销恢复，也能保存重开；空对象没有可见表面可点，应从树中选择。

Object 模式 Delete 仍删除整个对象及子树，X 不作为对象删除快捷键。既有对象 Delete
操作在 Edit 中继续拒绝，避免组件菜单与整对象删除混用。

## 补面：F

1. 例如先从 Cube 删除一个面，留下四条边界边。
2. 切到点或边选择域，完整选择这一个洞口的边界点/边（不包含其他洞口）。
3. Blender 风格按 `F`；或菜单“编辑 → 组件变换 → 补面（单个共面边界环）”。
4. 成功立即形成一条“补面”历史，切为面域并选中新面，可继续 G/R/S、挤出或内插。

Legacy 的 F 仍是聚焦；补面使用菜单/F3/Q。面选择域不能补面，至少三个边界点/边，
必须组成唯一闭合、共面、无自交的简单环。支持简单凹环，不支持多个环、带孔、分叉、
非共面、内部边、散点连面或已有面的反向重叠复制；不按点击顺序猜测连线。
点域从全部所选点诱导源边界；如有多个洞口共享候选点，改用边域精确选择一个环。

新面的绕序与相邻面的边界方向相反。原有顶点位置、面/角身份、材质与 UV/颜色/硬法线
不变。新面使用对象默认材质、白色顶点色、计算平面法线和局部平面投影 UV：以最小点 ID
为原点、第一条有向边为 U 轴，坐标除以边界相对原点的最大距离。不是恢复被删面原 UV
或材质；需要恢复原属性请用撤销。新面和角 ID 按当前最大值后分配，溢出拒绝。
共面误差按边界尺度相对检查（1e-6）；最终通过完整源网格校验与耳切派生。
不执行与远处面/其他对象的全局相交检测。

## 入口、事务与历史

Registry 增加 5 项，合计 52 项：`mesh.delete_menu`、`mesh.delete_vertices`、
`mesh.delete_edges`、`mesh.delete_faces`、`mesh.fill_face`。菜单/F3/Q 使用同一意图入口；
删除菜单冻结文档、对象、模式、网格 revision 与选择代际，弹出后目标变化则拒绝旧入口。
直接搜索“删除面 / Delete Faces”会立即执行，不再显示选择菜单；可 Ctrl+Z 撤销。

两种操作均先取消未确认的组件候选，基于已确认真源计算，不把预览意外写入文档。
独立候选通过校验后才安装，失败不改变源、revision、选择或历史。仍使用唯一 QUndoStack。
Undo/Redo 在仍编辑同一对象时恢复对应几何和选择域/选区，保存点正确恢复。
删除菜单本身不产生历史，删除/补面不提供 F9。文本、IME 预编辑和弹窗优先；
长按 X/Delete/F 不重复触发组件操作，模态中的 X 仍是轴约束。
