# 单面等距内插（MODEL-02）

## 使用方式与单位

选择可编辑网格，进入 Edit / 面选择，只选一个共面凸面。Blender 风格在视口按 `I`，
向右移动鼠标或输入正小数（例如 `I .2`）；Enter/视口内左键确认，Esc/右键取消整次操作。
菜单“编辑 → 组件变换 → 面内插（单个共面凸面）”、F3 搜索“内插 / Inset”以及 Q 收藏
共用 `mesh.inset_face`。Legacy 不绑定 I，使用上述替代入口。Registry 当前共 47 项（含环切）。

- 厚度是**对象局部单位**，不是世界距离；完整父变换不改变源网格的局部厚度。
  非均匀缩放后世界空间边框不一定等宽，HUD 和 F9 字段明确标注局部单位。
- 鼠标水平 200 逻辑像素对应当前面的首条边坍缩上限，向右增厚；不依赖屏幕物理像素。
  Shift 精细倍率 0.1，切换保持连续；Ctrl 临时反转局部厚度 0.1 的步进偏好。
  显式数字优先，不被步进舍入。X/Y/Z 不适用于内插，按下会解释原因而不改变候选。
- 厚度必须大于零且严格小于首条边坍缩上限。零、负值、上限及超限不得确认；
  非法文字保留，可退格修正。无效输入不会把上一合法预览误提交为新参数。
- 确认后左下出现折叠“调整上一步”；F9 展开同一面板并聚焦“内插厚度”。
  调参从原 before 重算、替换同一历史，不多生成第二圈。再次 I 才是新的内插操作。
  草稿、收起和失效规则见 [上一步参数](v2-history.md)。

## 几何与属性边界

只支持单个共面凸多边形，包含有效共线边点；不支持多面区域、凹面、非共面、自交环、
外插或无限延伸厚度。算法在归一化面平面偏移每条边，并求相邻偏移直线交点，
**不是中心缩放**。共面容差相对面尺度为 1e-6；到第一条边坍缩即拒绝，不自动消边。
原输入和完整候选均通过既有网格派生/拓扑校验；没有全局自相交检测。

中心面保留原 FaceId、CornerId 和材质，面角改引用新 VertexId；边框使用新的面/角 ID。
原边界顶点及邻面不移动、不改 ID。新 ID 从 before 的最大值后分配，空间不足拒绝。
原面角 UV、颜色与硬法线按原渲染三角形的重心坐标插值到内边，边框内边使用相同属性，
外边保留原角属性；法线插值后归一化。不是简单复制旧 UV 到新位置，也不新增 UV 编辑能力。
场景层仍保持现有材质引用限制，不扩展资产协议。

## 事务、历史与保存

每帧从冻结 before 求独立候选；预览只影响真实实体/组件覆盖层/N 侧栏，不改 Scene 真源、
dirty、历史或几何 revision。确认安装一次 after，形成一条“面内插”历史；Undo/Redo
安装快照并恢复该次面选区，revision 单调增长。中心面的稳定身份支持随后继续 E 挤出。

内插复用组件模态、唯一 QUndoStack 和 HistoryService。上一步参数为明确的两种类型：
挤出世界 vector3 与内插局部厚度 double；错用参数接口会拒绝，不猜测类型或悄悄换算单位。
可恢复的重算/提交准备分配失败沿用历史基础保护，不承诺系统、Qt 或驱动致命 OOM 可恢复。
F9 调整保存过的顶端会使工程重新未保存，不自动写磁盘。

Esc/右键、失活、文本/IME、视口/模式/选择/文档变化取消未确认候选；保存中途预览先取消，
再保存已确认几何。确认后保存重开保留多边形真源，不持久化编辑会话、历史或 F9 参数。
参数字段 Esc 清除自身错误并恢复草稿；Inspector/状态栏仍可能保留最近业务失败文字，
沿用既有 operationFailed 展示机制，不声称所有区域提示都同步清空。
