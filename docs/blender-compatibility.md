# Mini3D 与 Blender 的兼容边界

本页记录 V2 R2 当前已实现功能的边界，不表示全环境验收或正式发布。实施进度见
[二期计划](v2-development-plan.md)，实际验证见 progress.md。

- 操作参考固定为 Blender v4.5.0；HTML 历史图只用于区域与视觉层次，不作为逐像素标准。
- Mini3D 仍为右手 **Y-up**、地面 XZ；G→Y 为项目竖直方向。不是 Blender 的原生 Z-up。
- 仅单对象 Edit；静态 glTF 保留实际三角输入，不恢复丢失的原始四边形或按坐标焊接接缝。
- 模态操作采用原子安全取消。挤出 Esc/右键恢复整个 before，不留下零距离重叠面。
  环切确认后的 Slide 右键居中确认，Esc 取消整次操作。
- 挤出限连通可定向有效面域；内插限单个共面凸面且等距偏移；环切限无分叉规则四边形带。
  补面限简单共面无孔无自交边界。每个算子拒绝不支持输入并解释原因，不暗示任意拓扑支持。
- 框选规则按投影顶点、边段和面中心实现；Visible 检查遮挡，X-Ray 仍不选隐藏元素。
- Mirror 限一个局部轴、对象原点平面；Merge 限中心对应边界，Clipping 不是焊接的别名。
  外部镜像对象、Bisect、三轴组合、任意修改器重排不在本轮。
- P1 已实现并有定向检查：比例编辑为 Smooth 欧氏距离加 Connected 过滤，不是测地距离；
  倒角限单条外凸流形边、单段；细分为限定流形四边形 Catmull–Clark 1–2 级，非三角细分替代。
- 不支持 .blend、动画、雕刻、节点、完整渲染器、任意分屏、多对象同时编辑；不加入假时间轴。
- 拓扑校验不等于全局自相交检测，未测项明确标“未检测”；渲染三角对角线不是可编辑拓扑边。
- Mini3D 保留独立品牌。图标自制或使用明确许可资源，不挪用截图内人物资产或 Blender 品牌。

当前默认 Blender 风格键位，可通过“编辑 → 键位配置”切回 Legacy；G/R/S 随模式分别
变换对象或所选源组件，不改坐标约定。组件支持选择质心/活动元素/游标三种枢轴，见 [变换枢轴](v2-pivot.md)。
当前写 3、读 1/2/3；旧工程首次升级须另存新路径。最小网格字段已经接通，完整修改器/
editorState 已接通并完成 FILE-01 定向检查。Tab、点/边/面点击、Shift 多选、B 框选、X-Ray 与独立覆盖层开关
已接通；框选为触碰规则（点投影 / 边段 / 面中心），详见 [组件框选](v2-component-picking.md)。
区域挤出已接通，支持非共面连通区域及不接触的多边界环；保留顶盖属性与身份，
默认区域法线抵消时用最小所选面法线并提示。零距离或退化侧壁不得提交，
Esc/右键恢复整个 before，详见 [区域挤出](v2-extrude-region.md)。
单个共面凸面 I 内插已接通真实边线等距偏移，厚度为对象局部单位，非均匀缩放后不宣称
世界等宽；零/超限拒绝，Esc/右键安全取消，见 [面内插](v2-inset-face.md)。
Ctrl+R单环切已接通两阶段：预览右键取消，滑移右键居中确认，Esc整次取消；无多切、
Even或端点焊接，拒绝非四边面/高价极点/交叉面带，具体定义见 [环切](v2-loop-cut.md)。
Edit 的 X/Delete 删除菜单与 F 补面已接通，见 [删除与补面](v2-fill-delete.md)。
删除点/边会连带删除相邻面，删除面保留仍被其他面使用的边界；清理孤立点，不支持保留散边、
Only Faces 或 Dissolve。补面仅接受单个源边界环，不支持散点连面，按邻面反向确定绕序。
挤出 F9 与左下参数面板已接通：世界全局 XYZ 位移、原 before 重算、同一历史替换；
不是法线标量，也不宣称全部 Blender 操作都可重开。操作与限制见 [上一步参数](v2-history.md)。
内插 F9 使用局部厚度字段，同样替换原历史而不增加第二圈。
当前 Edit 仅支持原生 Cube 和已有可编辑网格，静态
glTF/球体/平面仍不能直接进入 Edit；具体规则见 [编辑模式](v2-edit-mode.md)。
F1 和帮助菜单已接通离线HTML与兼容性说明；开发态真实动作已通过三档DPR联调。

P1-SELECT/PROP/BEVEL/SUBDIV 已完成开发与定向检查：Alt/Ctrl+Alt边环/面环、悬停L，
O/滚轮Smooth比例编辑、Ctrl+B三价端角单段闭合倒角、1–2级四边细分和固定修改器链。
倒角五边端面与启用的四边细分不兼容；P1开发及定向检查完成，统一验收仍未完成。详见各操作说明。

基础集合已接通单层、单对象单归属、独立显隐、成员选择、复制/删除与唯一历史/格式3。
集合不是父节点，删集合保留对象；无嵌套集合、跨集合多链接或批量对象变换，
见 [集合管理](v2-collections.md)。

Z/反引号提供真实着色/视图饼菜单；材质是现有基础预览，Solid为中性色，
Wireframe包含渲染三角化边，不是新源拓扑或Rendered。
Shift+R仅重复当前末端挤出/内插/倒角，在当前源与选区执行并新增历史；
F9仍只替换原操作。详见 [饼菜单、着色与重复](v2-pie-repeat.md)。

1万源点基础预览在本机达预算，5万/10万正确性通过但超实时预算；更大Edit网格显示
常驻规模提示，详见 [性能说明](v2-performance.md)，不外推复杂拓扑/比例/修改器或其他硬件。
Blender5.1.1实际导入及有限Mirror→二级细分数值复核已通过，详情见
[二期验收证据](v2-acceptance.md)。它不替代固定参考4.5.0、真实IME、mixed-DPI或正式发布核查。
