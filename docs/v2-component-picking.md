# 组件框选、穿透与覆盖层（PICK-01）

## 操作规则

在可编辑对象的 Edit 模式中使用。当前仅原生 Cube 或已有可编辑源网格能进入 Edit，
静态 glTF/球体/平面的转换不属于本项。组件变换与拓扑操作仍按二期计划后续实现。

| 操作 | Blender 风格快捷键 | 菜单 / Header 替代入口 |
| --- | --- | --- |
| 启动框选 | B，然后左键拖动并释放 | 编辑 → 模式与组件选择 → 框选组件；F3 / Q |
| 替换选区 | 无修饰键拖动 | 相同；空框清空选区 |
| 追加 / 移除 | 按下左键时按住 Shift / Ctrl | Ctrl+Shift 同时按下时以移除为准 |
| 取消框选 | Esc / 右键 | 离开视口后释放、切换上下文也取消 |
| 穿透选择 | Alt+Z | Header“穿透”；菜单“穿透选择（X-Ray）” |
| 覆盖层总开关 | Shift+Alt+Z | Header“覆盖层”；菜单“显示覆盖层” |

Legacy 不添加 B / Alt+Z / Shift+Alt+Z 别名，保留菜单、Header、F3/Q 替代入口。
文本、数值框、IME 和弹窗优先；例如文本框中的 B 不启动框选，Alt+Z 不改变穿透状态。
切换键的自动重复不会反复翻转状态。既有 A / Alt+A 和 Shift 单击规则不变。

框选采用固定的“触碰”规则，与拖动方向无关：

- 点：投影点落在矩形内。
- 边：经过视锥裁剪的源边，有一段投影进入矩形；不要求两端或中点在框内。
- 面：面角顶点均值中心投影在矩形内；不是所有渲染三角或面外接框进入矩形就选中。
- Visible：上述候选还须通过真实三角深度检查。边只需框内部分存在未遮挡区间。
- X-Ray：取消几何遮挡限制；投影仍须在视锥内，隐藏对象及其后代始终不可选。

不把三角化对角线当成源边。X-Ray 单击仍优先屏幕距离、深度、稳定 ID，不提供重叠元素
循环选择；要选择同一投影后的多个元素，可以使用框选。面单击仍用精确射线定位源面。

## 一次性选区更新与取消

B 启动时冻结编辑对象、MeshId、求值 revision、选区/选择代际、选择域、观察相机、
真实视口逻辑尺寸和穿透状态。拖动仅显示矩形和中文提示，释放后批量更新一次选区。
批量操作保留仍有效的活动项，否则取最小稳定 ID。无变化不通知，选择不产生历史或 dirty。

Esc、右键、失焦、窗口失活、视口隐藏/尺寸变化/丢失鼠标捕获、模式/选区/网格/文档变化、
观察方向/投影/穿透状态变化、键位切换会安全取消。新的文件、帮助、搜索、模式等键盘
意图先取消框选再交回 Router。释放位置在视口外取消，不把侧栏坐标折算为模型坐标。
取消不恢复旧场景覆盖用户新改动，因为框选预览从未写入几何或选区。

## 拾取与显示边界

点选和框选使用同一 CPU 查询策略。源点/边与场景遮挡三角均做六平面齐次裁剪；跨近面、
远面或侧面的边保留可选部分。可见线段通过投影重心权重和深度的线性不等式求连续区间差，
不是固定步长采样，也不以中点替代部分遮挡检查。NDC 深度容差为 `2e-6`，避免共面自遮挡。
材质单双面、负行列式世界变换与 Renderer 的绕序规则一致；隐藏场景几何不遮挡。

鼠标、框选、命中半径使用逻辑像素，点显示大小再乘 DPR；10 DIP 点/边命中半径不随
系统缩放改变。N 侧栏位于独立布局区，不是覆盖在 GL 视口上的透明输入区域。

穿透与覆盖层是两个独立的视口会话状态，不写项目文件、不改变材质透明度或线框着色。
穿透开启时源组件覆盖层不检查深度，真实实体表面仍正常着色。关闭覆盖层隐藏地面网格、
组件选区、对象包围盒与手柄；不退出 Edit、不清空选区、不关闭 X-Ray，仍可选择。
进行中的框选矩形和操作提示属于交互反馈，覆盖层关闭时仍可见。

GL 资源仅在有效 Context 中上传/销毁。显示开关不改变几何 revision 或重新上传相同缓冲；
覆盖层绘制后恢复深度开关/写入/函数、混合、剔除和点大小。未重挂 QOpenGLWidget。

元素 H/Alt+H 隐藏掩码在 VIS-01 实施，本项已接通的是对象/祖先隐藏过滤。
CPU 查询尚未增加空间加速或承诺大模型速度；1万/5万/10万点及 P95 预算仍由 PERF-01 实测，
本项小场景测试不能证明这些性能目标。F1 集成、真实输入法与跨屏测试仍在最终 QA。
