# Camera 与 Directional Light 补齐

本轮范围由用户于 2026-09-10 确认，补齐原 P0 独立实体及场景格式；不包括公开发布。

## 组件与变换契约

Camera、Directional Light 是带独立组件的 Empty 几何节点，不绘制成网格。
与 MeshRenderer、内置几何及另一种设备组件互斥。参与既有稳定 ID、层级、复制与子树恢复。

Camera 为透视相机，垂直 FOV 默认 45 度（1–179），近裁剪默认 0.1（至少 0.001），
远裁剪默认 1000（大于近裁剪且不超过 1000000）。局部 -Z 朝前、+Y 朝上。
位置使用完整父子 TRS；朝向只组合祖先与自身四元数，忽略缩放和镜像，支持 roll 和垂直观察。

Directional Light 的颜色为 RGB [0,1]、强度 [0,10]，局部 -Z 为光传播方向。
位置和缩放不影响照明；旋转含祖先旋转。环境光仍是全局参数。
仅 ID 最小的可见方向灯生效（不叠加）；祖先隐藏也使灯失效。
存在灯实体但全部隐藏时只有环境光；完全无灯时使用原全局方向光，保持旧场景外观。

## 场景格式 2

写入 `version: 2`，仍读取 `version: 1`。旧文件不自动增加设备节点，原全局光照和
编辑器观察相机保留；再次保存升级为 2。旧程序不能读取新版，请用另存为保留旧稿。
`entities` 中按需新增以下字段，其余字段、相对模型路径和四元数 w/x/y/z 顺序不变：

```json
"camera": {"fieldOfView": 45, "nearPlane": 0.1, "farPlane": 1000}
```

```json
"light": {"type": "directional", "color": [1, 1, 1], "intensity": 0.72}
```

组件字段一旦存在就必须完整有效；无效范围、类型、组件互斥冲突或未知格式版本均拒绝。
旧版仍按旧字段集解读并忽略未知字段。预览状态不持久化，不替代 `editorCamera`。

## 使用方式

1. 创建 → 相机：以当前编辑器观察位置/朝向创建相机，在场景树中选中。
   属性面板的相机区可调垂直视角（度）、近裁剪、远裁剪，非法近远关系恢复原值并提示。
2. 点击“预览所选相机” 进入该实体视角，宽高比跟随当前视口，隐藏 Grid/选中框/手柄。
   这是只读视口预览：暂停导航、拾取、移动和 F 聚焦，避免改动隐藏的编辑相机。
   仍可从树选对象、在属性面板编辑变换/组件，画面实时更新。
3. 点击“返回编辑视图”或在视口按 Esc 退出，保留原编辑视角。
   删除/隐藏该相机或其父节点、新建/成功打开文档也退出；打开失败保留当前预览。
4. 创建 → 方向光：以兼容全局光照的颜色/强度/朝向创建。
   选中灯可编辑颜色/强度；修改旋转参数改变照射方向，“光源方向”显示只读世界方向。
   存在设备灯但没选中灯时，停用旧全局方向/颜色/强度控件；“环境光”始终是全局设置。

两种实体支持名称、显隐、换父、局部 TRS、复制/删除、撤销/重做及保存加载。
从场景树选择设备，在普通编辑视图可用现有 W 世界移动手柄；没有设备图标、网格、
视锥绘制或设备射线拾取。F 沿用几何包围盒规则，不聚焦无几何的相机/灯。
预览切换本身不标脏、不加入历史；组件和变换编辑会标脏并可撤销。
