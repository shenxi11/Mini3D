# 变换枢轴（PIVOT-01）

## 操作与语义

视口头部“枢轴·…”与“全局 / 局部”是两个独立菜单。前者决定旋转、缩放的中心，
后者决定方向；也可用“编辑 → 变换枢轴”、F3 搜索或 Q 收藏同一动作。

| 枢轴 | 编辑模式 | 当前单对象模式 |
| --- | --- | --- |
| 选择质心（默认） | 选区转为去重源顶点集合后的世界平均位置；共享点不重复计权 | 对象世界原点 |
| 活动元素 | 活动点位置、边中点或面顶点均值；活动项移除后沿用稳定ID回退规则 | 对象世界原点 |
| 3D 游标 | 游标世界位置 | 游标世界位置 |

例如，把游标放到世界原点，选择位置为 (1,0,0) 的立方体，选“3D 游标”枢轴，
全局 `R Z 90` 后对象原点变为约 (0,1,0)；`S 2` 会把对象原点到游标的距离放大两倍。
编辑模式同样围绕冻结枢轴变换所选源顶点，不移动对象原点；未选顶点保持不变。
只选一个点时，质心 / 活动枢轴的 R/S 无变化；切游标枢轴才可让该点绕另一位置运动。

对象模式的旋转 / 缩放手柄与模态 R/S 都遵守此设置，绘制和拾取也使用游标位置。
组件仍通过 G/R/S 操作，不新增组件手柄。移动 G、挤出 E、内插 I、环切不随枢轴改变算法。
未约束旋转沿视线轴，轴二按切换空间，数值、Shift精细、Ctrl临时反转步进沿用既有规则。
主键区句点枢轴饼菜单没有接入，不把它与小键盘聚焦混淆。

## 选择到游标（保持偏移）

“编辑 → 3D 游标 → 选择到游标（保持偏移）”及 N 面板同名按钮可将：

- 单对象的世界原点移到游标，保持父级、旋转和缩放；父级有旋转 / 负非均匀缩放时换算回局部位置。
- 组件选区的去重顶点质心移到游标，所有选中顶点使用同一世界位移；保持选区内部形状和组件选择。

这个操作固定按质心定位，不受当前 R/S 枢轴模式影响；不会把顶点逐个压到同一点。
无选区、隐藏目标、相机只读预览时拒绝。若候选网格不合法，原子拒绝，不留下半次位移。
“游标到选择”只移动游标；“选择到游标”会修改对象或网格，请区分方向。

## 历史、生命周期与边界

枢轴模式是当前编辑器窗口偏好，初始为质心，不标脏、不入撤销，也不写入工程。
同一窗口新建 / 打开保留该偏好，新开窗口恢复质心。游标的位置仍随显式保存落盘。
几何操作确认后只有一条历史，取消不留历史；Undo/Redo 不回退枢轴偏好。
切换枢轴或修改游标位置会取消尚未确认的变换，再使用已确认状态计算下一次操作。
模态开始冻结世界枢轴和方向空间，不跟随预览后的质心 / 活动点逐帧漂移。

对象全局缩放继续采用既有“保旋转、换算缩放分量”的 TRS 规则，不把旋转对象改成剪切矩阵。
非均匀父级下无法表示为局部 TRS 的全局旋转仍拒绝；可改局部旋转或在编辑模式变换顶点。
不引入 Individual Origins、包围盒中心、多对象编辑、游标朝向或新的顶点吸附。
若枢轴在观察相机近裁剪面后方，模态提示调整视角；这不是几何被删除。
