## ADR-01：输入、坐标与取消

保留右手 Y-up，地面 XZ。Header/帮助注明“Y↑项目”；Blender-style 指操作习惯，
不声称轴方向与 Blender 原生 Z-up 等价。不借二期机会改坐标或偷偷旋转导入结果。

两配置互斥，不同时保留冲突快捷键；Emulate Numpad 默认关闭。键位偏好不标记项目修改。
INPUT-01/02 通过后已切 Blender 默认，Legacy 可在“编辑 → 键位配置”选择并保留偏好；
新 R 为即时旋转，旧 R 为缩放手柄，不混用。Edit 与挤出/内插 F9 已接通；其他未实现入口不开放。

输入路由优先级：系统、文本与 IME → 弹窗/数值输入 → 冻结的模态会话 → 鼠标区域与模式
→ 应用文件/帮助。不得在 enterEvent 强制 setFocus，编辑名称时 GRS/T/N/Tab 不触发建模。
F3 打开前冻结文档与调用区域；执行时重新校验冻结文档仍有效，而非搜索框成了工作上下文。

一次模态操作冻结 before、文档身份、MeshId、BaseRevision、选择、轴空间与枢轴。
每次预览从 before 重算；不把上一帧结果累乘。Shift 精细保持连续；Ctrl 对偏好吸附取反。
Enter/左键确认一次；Esc/失焦/文档切换恢复；右键按算子阶段：普通变换/挤出取消，
环切预览取消，环切 Slide 居中确认；Esc 在 Slide 阶段恢复整个操作前。
无变化不入历史；挤出零距离或非法侧壁拒绝，避免重叠面残留。
MODEL-03环切已实现上述两阶段；滑移0%中点是有效的新拓扑，不能按“零位移无变化”丢弃。
预览的新边选区仅供覆盖层/N侧栏显示，原输入域与选择代际不变；确认才发布新边域和选区。
环切为普通快照历史，当前不开放reopen/F9，详见 [环切](v2-loop-cut.md)。

工作区只是布局和工具偏好；Object/Edit 是文档上下文；不能以切工作区替代模式状态机。
单对象编辑；相机、灯和不支持对象拒绝 Edit，并展示原因。

## ADR-02：EditableMesh、快照和格式 3（2026-09-12 已授权）

### 数据权威与所有权

SceneNode 只能绑定静态网格或 EditableMesh 之一，避免 primitive/static/editable 三重来源。
EditableMesh 属 Core、由文档持有，不依赖 Renderer 或 Qt Widgets。真源保存稳定 VertexId、
FaceId、CornerId 和多边形环、面角 UV/硬法线/材质引用。边以有序端点 ID 键生成，
邻接可重建；遍历下标不能成为外部持久 ID。

原生 Cube 为 8 个拓扑点、12 条边、6 个四边面；渲染拆分为法线/UV 可产生更多点。
glTF 输入先保持实际三角拓扑，不能按坐标自动焊 UV 接缝或推测原始四边形。
共享静态资源首次编辑创建独立网格副本，不默默影响其他实例。

输入校验至少覆盖：有限数、唯一 ID、存在的引用、三个以上不同顶点、重复邻接顶点、
零面积/允许的邻接与一致绕序。未实现全局自交检测时不宣称模型没有自交。

### 求值、映射与版本

`SourceMesh → Mirror（单轴）→ 可选 Subdivision（P1）→ EvaluatedMesh → RenderMesh`。
修改器不改源；应用一次性安装合法求值快照，撤销恢复源/修改器/选择。反射处理绕序与法线。
源边是编辑笼；三角化对角线不是编辑边；每个渲染三角映射 SourceFaceId，
每个渲染顶点映射 SourceVertexId/CornerId，镜像生成部分明确只读。

TopologyRevision、GeometryRevision、EvaluationRevision 由拥有者递增，Undo 内容回退但
revision 不倒退。缓存按网格身份和 revision（或等价明确失效通知），不能仅按 AssetId。
预览用独立快照；GL 资源上传、替换、释放始终在有效 Context，不在鼠标移动中重建 Qt 树。

### 历史与 F9

SceneViewModel 继续独占一个 QUndoStack。HistoryService 只是适配，不是第二栈。
命令拥有 before/after/结果选择，安装快照不再执行一次算法。无变化不产生历史。
F9 仅当前历史顶端、可重开的最后建模操作：基于原 before 离线求候选并完整校验，
HISTORY-01 采用同一命令内替换已准备 after 的实现，保留原 before 和一条逻辑记录。
原建议的 undo/push 原型存在临时回退后再分配命令/容器的失败窗口，因此本实现调整时
不增删栈项、不触发 Qt redo、不产生中间 before 通知；首次确认仍正常 push 快照命令。
先验证纯历史夹具，涵盖失败、无变化、撤销后非顶端、保存点失效与注入的分配失败。
导航可保留 F9；其他数据修改/切文档后失效。保存后替换必须 resetClean 或等价策略，
不能以相同 index 误判未修改。选择与几何一起恢复，拒绝候选不改文档或旧历史。
实现及故障注入边界见 [F9 历史与参数](v2-history.md)；HISTORY-02 已接入同一左下可折叠面板、
F9/菜单/F3/Q。挤出字段提交世界 XYZ，内插字段提交对象局部厚度；参数通过 vector3/double
区分，错用类型拒绝。收起丢弃未提交草稿，失效禁用并解释；不重挂 GL 控件。

### 格式轮廓与迁移

`format=Mini3DScene`、`version=3`；Reader 接受 1/2/3，其他版本拒绝且不修改当前文档。
保留格式 2 相机、灯、meshIndex、相对资源路径、TRS 和 WXYZ 字段含义，不挪用字段。
新增 editableMeshes（身份、顶点、多边形、面角、材质）、对象绑定、modifiers、
editorState（游标、Y-up 与必要视图状态）。实际 schema 和迁移夹具随读写实现一起交付。
项目不保存完整 Undo 历史；保存当前真源和修改器参数。游标移动不标脏，下次保存才落盘，
UI 明示此区别。相机导航维持旧规则：参与修改判断、不进对象历史。

旧文件加载到临时 Scene/Assets，全部资源和拓扑通过后再发布。格式 1/2 迁移后首次保存
要求新路径，不自动覆盖唯一旧工程；使用现有 QSaveFile 原子写。坏 JSON、无效 ID、
缺资源、无效修改器或求值失败均保持当前文档/选择/历史。

OBJ 导出由用户选真源或求值结果，明确 Y-up 与单位；验证面数/绕序/法线/比例，
不是仅测试其他工具能够打开。不得自动发布用户模型或覆盖原始输入文件。
