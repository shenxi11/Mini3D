# 3D 游标（CURSOR-01）

## 能做什么

在场景中指定一个世界位置，精确调整 XYZ，再以该位置为中心创建立方体、球体、平面或空对象。
游标是红白圆环与十字，不是场景树节点，不会成为对象/组件选择，也不参与父子关系。
后续 PIVOT-01 已接入游标枢轴和“选择到游标（保持偏移）”，见 [变换枢轴](v2-pivot.md)；
本项原游标定位与保存语义不变，不改现有步进吸附。

## 操作

1. 默认 Blender 键位下，将鼠标移到视口，按住 Shift 再单击右键。
   两套键位均可从“编辑 → 3D 游标 → 点击放置 3D 游标”启动，再左键放置一次。
   菜单方式可用 Esc/右键取消；失焦、失活、切文档/视角/选区或启动其他会话也会取消。
2. 点击优先取最近可见的真实三角表面，包括基础体、可编辑网格和静态导入模型。
   遵守隐藏父级、材质单双面、负尺度绕序、近远裁剪；不以对象包围盒代替表面。
   没有命中时求 XZ 地面（Y=0）。视线近平行或交点在视野外时保留原位置并解释原因。
3. N 面板的“3D 游标 · 世界坐标”支持 XYZ 数值，Enter/失焦提交、Esc 恢复，Alt 拖动微调。
   非法值不会写入。侧栏可滚动；窄窗口会优先保留视口，扩大窗口后可重新打开 N。
4. “游标到选择”：对象模式取所选对象的世界原点；编辑模式取所选源顶点去重后的世界质心。
   面/边共享顶点不会重复计权。无选区禁用。“游标到世界原点”恢复 (0,0,0)。
5. 返回对象模式，用“创建”菜单添加基础体。对象位于根层，初始位置取当时的游标，创建是一条历史。
   隐藏游标或关闭覆盖层不改变创建位置。相机仍从编辑视角创建，方向光和模型导入行为不变。

F3 可搜“游标”或 Cursor，Q 可收藏同一批真实动作。相机只读预览中不能定位游标。
正在 G/R/S、框选或环切时，右键优先服务原操作，不同时放置游标。

## 保存与撤销

游标移动/显示不进入唯一撤销栈，不改变文档星号，不弹未保存提示。
几何 Undo/Redo 不回退游标，重做创建仍使用当时的位置，不使用后来移动后的游标。
下次主动保存时，将游标位置和显示写入 `editorState.cursor3D`；只移动游标后要保留位置，
也需要 Ctrl+S。新建复位为原点/可见，打开恢复，旧文件缺字段使用默认值。
失败加载不替换当前状态。格式细节见 [格式 3](v2-scene-format.md)。

## 验证入口与限制

- CPU `[cursor-serializer]`：字段往返、1/2/3 缺省、非法类型/数值原子拒绝。
- Assets `[cursor-picker]`：表面与平面、父变换/负尺度、隐藏、球体非 AABB 命中、透视/正交、平行拒绝。
- Editor `[cursor-editor],[cursor-ui]`：不脏/历史隔离、创建与重做、保存重开、选择中心、N/F3/菜单、
  输入及会话取消、真实帧缓冲、覆盖层、GL Context 与截图。
- 独立本机验证脚本：`out/validation/v2-cursor01-verify.ps1`；实际最终统计记录在 progress.md。

尚不承诺 Blender 的游标朝向、拖动笔刷式放置、自定义工作平面或自动视图平面。
游标在视野内不被模型深度遮挡；关闭自身显示或总覆盖层、进入相机预览或离开视锥时不显示。
测试使用真实 Qt/GL 和合成输入，不等于实机输入法、跨屏 DPI 或完整二期人工验收。
旧 V1 候选包未更新，请使用当前源码构建。
