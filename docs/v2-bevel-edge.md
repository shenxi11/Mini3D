# 单条边倒角（P1-BEVEL）

Edit 中切换边选择，只选择一条外凸源边，按 `Ctrl+B`，或使用“编辑 → 组件变换 → 边倒角”及 F3/Q。

- 向右移动鼠标增宽，或输入正数（例如 `.2`）；宽度为对象局部垂距单位。Shift 精细，步进使用既有吸附开关及 Ctrl 反转。
- Enter/左键确认一次历史；Esc/右键恢复整个 before，不留下零宽度倒角。
- 确认后选择新倒角面；F9 左下“宽度”字段从原边/原网格重算，替换同一历史，不再倒第二次。
  若隐藏了新结果面，F9提交拒绝且保持保存点；Alt+H揭示后可继续调整。
- 零、负、非有限或达到/超过上限的宽度不提交，可以继续修正数值。HUD 显示严格宽度上限。

## 支持限制

只支持单条两面流形外凸边、三价端点，两邻面和两个独立端面必须为共面凸环。算法生成四个交点，重写邻面和两端面，新增一个闭合倒角面；不是会留下孔洞的装饰条。

边界边、凹边、平边、复杂/高价端角、非共面邻面、隐藏受影响面及超宽明确拒绝。不支持多条边、多段、圆角轮廓或全局自交检测；保留未影响身份及逐角属性，受影响法线重新派生。

Mirror 可继续求值。倒角会产生五边端面，而当前启用的 Subdivision 只接受全四边输入，所以该组合会明确失败且保留原源，不自动关闭细分。比例编辑仅普通 G/R/S 使用，不作用于倒角。
