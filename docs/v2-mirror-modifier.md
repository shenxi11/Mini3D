## 用户操作

先将对象转换为可编辑网格，再在“修改器”属性页添加 Mirror；静态对象不会被隐式转换。
支持启用、X/Y/Z 单局部轴、中心边界 Merge、局部距离阈值和 Clipping。编辑页面参数后，
Scene 先验证真源与求值结果，成功才形成一次可撤销修改。删除只移除参数，保留真源；
应用把当前求值结果变成可写真源并移除参数，撤销恢复原真源、参数和组件选区。
停用状态的求值等于真源，因此停用后应用只移除参数。

## 数据与显示

每个 EditableMesh 仍只绑定一个对象。不可变内容同时保存真源、真源派生、可选参数及
完整 MirrorEvaluation（最终 EditableMesh、派生三角形与来源映射）。GPU 缓存按求值 revision
和可见性 revision 刷新；显示、遮挡、游标和聚焦读取最终求值几何。组件点/边/面只从真源
拾取与编辑；镜像侧作为只读遮挡及吸附目标，生成 ID 不成为可写源选择。临时隐藏对
镜像面查来源面过滤。G/R/S 每次以冻结的 before 使用 MIRROR-01 Clipping 会话；
拓扑操作只做完整求值校验，不扩展 Clipping 语义。

格式 3 在 `editableMeshes[]` 上增加可选 `modifier`；旧文件无字段默认无修改器。
字段和值严格解析，非法参数或求值结果导致载入原子拒绝。格式 1/2/3 读取保持。
详见[格式 3](v2-scene-format.md)和[结构 Schema](scene-format-v3.schema.json)。
