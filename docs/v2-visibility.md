# 元素隐藏与局部隔离（VIS-01）

## 当前能力

2026-09-19：接通临时隐藏、恢复显示和 Local View。适用于当前 V2 源码，旧发布包与 HTML 手册尚未更新到本项。
隐藏只改变观察范围，不删除几何、不修改场景树的持久“可见”属性，不增加撤销记录，也不因隐藏本身标脏。

| 入口（Blender 键位，鼠标位于视口） | 对象模式 | 编辑模式 |
| --- | --- | --- |
| `H` | 临时隐藏所选对象及其子树，清除对象选择 | 隐藏当前点/边/面选区，清除不可见选择和活动项 |
| `Alt+H` | 恢复本窗口临时隐藏的对象 | 恢复当前编辑网格的隐藏元素 |
| 小键盘 `/` | 隔离所选对象及其子树，再按退出 | 隔离当前编辑对象及其子树，再按退出 |

也可通过“视图”菜单、F3 搜索“隐藏 / 恢复隐藏 / 局部视图”调用；三个动作可加入 Q 收藏。
Legacy 键位使用菜单/F3/Q，不占用 H 或 `/`。主键盘 `/` 不等同于小键盘 `/`；没有小键盘时使用菜单。
文本框、数值输入和输入法预编辑继续优先处理按键，不会因输入 H 隐藏模型。
状态栏右侧显示局部视图或临时隐藏提示，局部视图菜单也保持勾选。

## 建议验收步骤

1. 创建两个立方体，选中其中一个，按小键盘 `/`。视口只显示该对象的子树，场景树仍保留全部对象。
2. 再按小键盘 `/`：恢复原显示范围。原先在场景树取消“可见”的对象仍隐藏。
3. 选中立方体，Tab 进入编辑模式，切到面选择，点击一个面后按 H。该面不再绘制，但相邻可见面的共用边仍能显示。
4. 开启穿透选择并按 A 或使用 B 框选，隐藏元素仍不会选中。按 Alt+H，隐藏面重新显示，但不会自动选回。
5. 撤销一次几何修改，或保存后重新打开工程：几何修改仍按原撤销栈工作，保存的是完整网格，不会把临时隐藏当成删除。

## 三种状态的边界

- **持久对象可见性**：场景树/属性中的“可见”属性，随工程保存，保留原有历史行为。Alt+H 不强行打开此属性。
- **临时隐藏**：对象 H 是窗口内对象子树掩码；组件 H 是当前单对象编辑会话的稳定元素 ID 掩码，不写工程。
- **局部隔离**：只允许隔离根及其后代显示，并与前两种状态相交。非隔离成员的祖先仍提供父级变换，不能因此改变子对象位置。

Alt+H 不自动重选恢复项，保留当前仍可见的选择；完全隐藏后的空选区没有活动项。
H 隐藏点会同时隐藏关联面；隐藏边会同时隐藏邻接面。隐藏面后，只有不再属于任何可见面的边/点随之消失。
孤立点仍可选，除非显式隐藏。隐藏不是冻结或断开拓扑：编辑可见部分的共用顶点，仍会影响相连的隐藏面。

## 一致性与安全规则

- 点选、框选、A 全选、选择域切换及历史恢复均过滤隐藏元素；X-Ray 只绕过遮挡，不绕过隐藏。
- 隐藏面既不绘制，也不参与 CPU 三角遮挡；游标表面定位和顶点吸附不会命中隐藏目标。
- 对象射线选择、所选/全部聚焦、选择包围框及对象手柄遵守同一掩码；全部隐藏时不聚焦到不可见几何。
- 环切面带若包含隐藏面，整次预览拒绝并提示先 Alt+H。不会在背后默默补切隐藏面。
- 隐藏、恢复和隔离切换取消尚未确认的变换/环切/框选及游标放置，不把预览提交进历史；模态内普通字母仍按既有模态优先级处理，可先 Esc 再按 H。
- 隔离切换本身不移动相机；可自行聚焦或导航。退出恢复显示范围，不回退隔离期间主动进行的相机导航。
- 局部隔离只处理对象几何显示，灯光仍沿用场景有效灯光规则，不临时改写灯光、材质或资源。

## 生命周期

- 退出编辑模式、切换编辑对象或失去有效编辑上下文，会清除该编辑会话的元素隐藏。
- 对象临时隐藏在编辑模式切换间保留；对象模式 Alt+H 才恢复对象隐藏。
- Undo/Redo 撤销的是几何或文档操作，不撤销隐藏/隔离。恢复出来的稳定元素 ID 若仍在本会话隐藏集合中，继续隐藏，不能恢复为不可见活动项。
- 在场景树选择隔离范围外的对象时自动退出隔离；删除隔离根或将其持久隐藏也退出。撤销删除不会自动再次隔离。
- 进入相机预览先退出编辑模式和局部隔离。预览期间隐藏/恢复/隔离入口不可执行。
- 新建或成功打开工程清空全部临时可见性；保存保留完整网格与原持久 visible，不保存本项掩码。
