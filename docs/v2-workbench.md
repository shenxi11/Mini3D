## UI-01（2026-09-11）

已把真实 C++ 窗口改为右上场景树、右下属性区；中央 WorkbenchShell 承载 Header、
当前工具说明、自制图标工具条与独立视口侧栏。现有文件/创建/树/属性/相机与灯/历史入口保留。
控制台默认隐藏，仍可从“视图”打开。没有假时间轴或未实现的建模按钮。

工具条复用原有 QAction，Header 的视图、坐标系、步进吸附与原菜单同一业务入口。
侧栏当前只读显示所选对象及局部位置，数值编辑仍在属性区；后续任务才接组件与游标。
UI-01 验收时仍为 Legacy，最初通过“视图 → 视口工具条 / 视口侧栏”切换。
随后已完成 T/N、工作区偏好、属性分类和新默认键位选择；当前操作见 [输入说明](v2-input-operations.md)。

侧栏与 GL 视口分别占据布局矩形，不叠在拾取区域上。宿主宽度不足 580 DIP 时自动关闭
N 侧栏以保留视口，扩大窗口后可重新打开；显隐不改文档、选择、历史，也不重挂 GL Widget。
场景变更明确刷新子 Viewport，避免 centralWidget 改为宿主后停止刷新。

- 新增 `[workbench]` 两用例，带截图运行 35 断言通过：区域位置、侧栏不穿透、真实 DPR
  帧缓冲尺寸、Context 身份/无销毁、动作复用、只读选择显示、最小窗口可用。

### 发现与修正

首轮最小窗口同时开侧栏时视口仅 156 DIP，已增加窄窗自动收起规则。

现提前应用主题，再创建控件/计算尺寸，原汉化与文件菜单布局断言全部通过。
旧吸附测试固定 40 像素在加高视口中不足半步进，改按真实相机投影移动 0.6 世界单位；
仍断言双轴正向且 0.5 倍数、单条历史、撤销恢复，没有修改吸附算法或放宽断言。

此阶段还未完成 Blender 式属性布局、视口背景色、工作区切换或建模功能；不得将本页

## UI-02（2026-09-11）

已增加“布局 / 建模 / 检查”工作区。每区保留 Dock 布局、工具条/侧栏、属性页、折叠状态、
活动工具、坐标系与吸附开关；切换不修改项目或选择，不自动进入 Edit，不重新挂载 GL。
建模默认打开 N，检查默认显示数据与外观页并隐藏工具条；所有工作区控制台默认隐藏，
用户可按需要打开并保留在该区的布局中。

属性为左侧垂直分类“对象 / 数据与外观”，各有可折叠内容。位置/旋转/缩放和颜色/方向
采用纵向轴字段，保留数值范围/业务入口，避免三轴并排强迫属性栏挤占视口。
统一 13 DIP 字体，视口背景为方案 #3B3B3B（只改 Renderer 清屏常量，不改渲染管线）。

正式应用通过 Qt 默认用户设置的 `workbench/v2` 组保存偏好，正常确认关闭时写入，
启动布局完成后恢复。测试使用隔离临时 INI，未写真实用户设置。此组与 `.m3dscene`
分离，不参与脏标志。尚未加入键位偏好或 Edit，不能把“建模”工作区标签当作已可建模。

### 验证

- Debug/Release 构建、CTest 4/4，18.82s / 7.90s。
- 工作区/中文/相机专项 8 用例/230 断言通过；150%/200% 工作区/中文各 7 用例/182 断言。
- 新测试验证同窗切换与新窗从隔离 INI 恢复、折叠、坐标系、GL 身份、模式/选择/历史/dirty 不变。
- 旧“任意第一个 QScrollArea”断言会选到新分类页中尚未布局的隐藏页，已改为按稳定

## UI-NUMERIC（2026-09-11）

属性数值字段现在支持：

- 输入过程中不写模型；Enter 提交合法值，Esc 恢复已提交值。合法文本在失焦时也提交，
  保持文件保存前提交当前输入的既有使用习惯。
- 非法文本、超范围、非有限数保留原输入，显示错误边框和原因提示；不悄悄改回旧值。
  业务拒绝（如零缩放、近裁剪不小于远裁剪）同样保留文本，模型/历史保持不变。
- Alt＋左键在数字文本上横向拖动：从起始值重新计算候选文字，松开才写模型一次；
  拖动中 Esc、失焦或窗口失活取消，并释放鼠标。这里是字段候选预览，不宣称实时几何预览。
- 程序 `setValue` 仍走原有业务信号通道；没有替换 SceneViewModel 或新增撤销栈。

### 验证

Debug/Release 构建、CTest 各 4/4，21.42s / 8.28s。首轮数值专项 3 用例/34 断言通过后，
补充实际 QLineEdit 的 Enter/Esc、10001 超范围、nan 与 1e999；最终 200% 综合数值/工作区/
汉化 10 用例/227 断言通过。最终全套证据在 `out/validation/v2-numeric-debug.xml` 与
`out/validation/v2-numeric-release.xml`。定向格式、差异与 UTF-8 无 BOM/LF 检查通过。

当前已完成的是工作台与数值字段，仍使用 Legacy 键位与场景格式 2；新键位/统一操作/
EditableMesh/建模工具/格式 3/P1 仍依实施计划推进。核心协议和 P1 授权确认尚未收到，
不得据此页面宣称 V2 整体完成，也未生成正式发行版。

## INPUT-03：区域最大化（2026-09-11）

当前工作台支持 Ctrl+Space 或“视图 → 最大化当前区域 / 还原”，以及该组合的重绑定。
视口、场景树、属性和控制台复用原控件，仅临时改变区域显隐，不重挂 OpenGL 控件。
恢复 Dock 布局、浮动窗口原坐标和原焦点；切工作区或保存偏好前自动还原。
文本和输入法优先，Legacy 使用菜单；详细行为与验证见 [输入说明](v2-input-operations.md)。

此处新增的是区域显示能力，工作区标签仍不等于 Edit 已实现，格式仍为 2。
