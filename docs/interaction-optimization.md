# 高优先级交互优化

用户于 2026-09-10 确认现有功能验收通过，并授权按顺序实现以下六项。
不包含多选、精确三角形拾取、设备图标、渲染特效或性能重构；不公开发布。

## 顺序及验收标准

1. 旋转/缩放手柄：W/E/R 切换，拖动实时预览，一次释放提交一条历史；Esc/失焦取消。
2. 世界/局部坐标：绘制、拾取和拖动使用同一坐标基；切换取消未提交手势。
3. 平面移动与吸附：XY/XZ/YZ 平面，固定移动/旋转/缩放步进，保留可撤销事务。
4. 视图切换：前/侧/顶视图与透视/正交，导航、拾取、手柄尺寸一致；不改场景相机组件。
5. 文件拖拽导入：接受本地 GLB/glTF，复用已有导入、错误与历史，不引入网络/异步线程。
6. 场景树增强：拖动换父、中文右键菜单、搜索定位；保持局部 TRS、不允许循环父子关系。

每项分别完成实现、定向测试、回归与 progress.md 追加记录后再进入下一项。
共同验收包括 Debug/Release、中文输入快捷键隔离和 200% 缩放。

## 约定

- 继续单选；手柄围绕对象原点，不移动其他对象。
- 维持场景版本 2、兼容读取 1/2。工具、坐标系、吸附和投影切换作为会话 UI 状态，不扩展文件协议。
- 保留原有局部 TRS。世界旋转/非等比缩放若在当前父子变换下产生不可表达的剪切，拒绝该预览并中文提示；不近似扭曲模型。
- 缩放保留原有正负号，不允许拖过零产生奇异矩阵；镜像仍可通过属性数值设置。
- 世界/局部坐标基使用旋转方向，不把父级缩放混入手柄尺寸。
- 原候选包、汉化验证包和历史媒体不覆盖。回滚点：out/validation/interaction-before-20260910（140 个正式文件）。

## 结果

### 第 1 项完成：旋转/缩放手柄

视图菜单或树/视口焦点下 W/E/R 切换移动、旋转、缩放；再次切换当前工具可关闭。
旋转使用彩色环；缩放有轴端方块和中心等比方块。Esc、失焦、改尺寸、切换工具取消手势。
Debug 构建及 CTest 4/4 通过（interaction-stage1.log），含新增数学与真实鼠标历史测试。
世界缩放产生剪切时拒绝；局部坐标能力在第 2 项实现。

### 第 2 项完成：世界/局部坐标

视图 → 变换坐标系 切换世界或局部。手柄朝向只组合节点与祖先旋转，不包含缩放/镜像。
局部旋转修改自身四元数，局部缩放修改对应缩放分量，允许在非等比父节点下稳定编辑。
切换坐标系取消未提交手势。Debug 全量构建及 CTest 4/4 通过（interaction-stage2.log），
新增带旋转/负非等比父变换的数学检查和真实局部轴鼠标拖动/切换取消检查。

### 第 3 项：平面移动与步进吸附

已完成 XY/XZ/YZ 平面移动；菜单常驻吸附与 Ctrl 临时吸附。相对手势起点按移动 0.5、旋转 15°、缩放 10% 取整，释放只生成一条撤销。Debug 四组测试全部通过。

### 第 4 项完成：观察方向与正交

树/视口焦点下 1/3/7 切前/右/顶视图，0 返回自由方向，5 切透视/正交；也可用视图菜单。中键旋转退出预设，Shift+中键平移，滚轮缩放；切投影保持目标平面的尺度。顶视精确沿 -Y、屏幕上方为 -Z。

预设与投影不保存，文件保留自由观察方向，打开/新建恢复透视自由观察。平移、缩放、聚焦仍更新目标和距离。创建相机使用实际编辑视图姿态，但新建相机组件仍为透视，不复制正交投影。实体预览期间禁止切编辑视图方向/投影。

Debug 全量构建及 CTest 4/4 通过（interaction-stage4.log），含顶视矩阵/平行射线、导航、拾取、手柄、创建相机及快捷键隔离。

### 第 5 项完成：文件拖入

将资源管理器中的本地 GLB/glTF 拖到中央视口，复用文件菜单的同步导入。支持多文件、中文路径与大小写扩展名，每个成功文件一条撤销；源文件不会移动，保留模型自带变换，不按鼠标落点摆放。批内某文件损坏时报告错误，其余按顺序继续，已成功结果保留。

目录、网址、混合不支持类型与相机预览状态拒绝拖入。拖入时取消未提交手柄手势。大模型仍可能短暂阻塞界面，本轮未引入异步线程。Debug 全量构建及 CTest 4/4 通过（interaction-stage5.log），含真实控件上的模拟拖放事件、新建后的单次导入、撤销重做及错误保护。

### 第 6 项完成：场景树

将单个对象拖到另一对象中央可更换父对象，拖到树的空白区域回根层。保留局部 TRS，因此世界位置可能随新父对象变化；禁止自身/后代成父、跨文档拖放和兄弟行间排序。每次有效换父一条撤销。

右键对象提供重命名、复制、删除、显示/隐藏、移至根层和聚焦，右键空白不对旧选择执行操作。搜索框输入名称后回车或点击“查找下一个”，按不区分大小写的包含匹配循环定位，自动展开父层级，不隐藏其他对象。

Debug 全量构建及 CTest 4/4 通过（interaction-stage6.log）。模型契约、拖入/换父/回根、循环拒绝、跨会话拒绝、局部变换保持、中文搜索与右键操作撤销均有自动化验证。

## 最小人工验收

在 Qt Creator 重新构建当前源码并运行（旧候选 ZIP 没有这些改动）：

1. 选中立方体，W/E/R 各拖一次，Ctrl+Z 撤销；拖动中 Esc 确认取消。
2. 旋转父对象后切局部坐标，拖动子对象；开启吸附，核对移动 0.5、旋转 15°、缩放 10% 步进。
3. 1/3/7/5 切方向/投影，检查中键导航、顶视缩放和手柄拖动；0 返回自由方向。
4. 从资源管理器实际拖入一个 GLB/glTF，再撤销。自动化覆盖 Qt 拖放事件，但跨进程原生拖放仍建议手工复验；若编辑器以管理员身份运行，Windows 可能阻止普通资源管理器向其拖放，请以相同普通权限启动。
5. 场景树拖动换父、移回根层，测试搜索和右键；保存/重开确认对象数据保留、会话投影恢复默认。

未纳入：多选、兄弟行排序、Asset Browser、异步导入、精确三角形拾取及新渲染特效。世界变换产生不可表达剪切仍拒绝；大模型同步导入可能短暂等待。未重打包或公开发布。
