# 基础集合管理

集合是对象的组织归属，不是空对象，也不是父子层级。当前只支持单层集合，
每个对象最多属于一个集合；不提供集合嵌套、多集合链接或多对象同时编辑。

## 操作

1. 在右上大纲下方的“集合”列表点击“新建”，或用“编辑 → 新建集合…”/F3搜索新建集合。
   输入中文名称后确认；取消不修改场景。
2. 保持一个集合行选中，在场景树或视口选中对象，点击“移入”。原有集合归属会被解除，
   新归属不会改变对象父节点、局部变换或世界位置。
3. 点击集合内成员选择真实对象；集合行本身不是对象，不启动对象变换或Edit。
4. 双击集合名重命名；勾选/取消集合复选框显示/隐藏成员。对象自身visible保持原值，
   隐藏父对象所属集合也会隐藏其后代，直到对象及其祖先的所有可见条件恢复。
5. “移出”解除所选对象归属；“删除”只删除当前集合，成员对象全部保留。

新建、名称、归属、显隐、删除均进入现有唯一撤销历史。重复同值操作不添加历史。
组织操作会结束当前变换预览；隐藏编辑对象会退出单对象编辑，不允许编辑隐藏几何。
复制对象/子树保持对应集合归属；删除对象清理成员引用，Undo恢复引用和对象。

## 保存与边界

格式3保存集合名称、身份、visible和成员ID；选择、展开状态和Undo栈不保存。
旧文件没有集合时正常加载；无效集合或不存在/重复成员会原子拒绝整份文档，
不替换当前文档，也不损坏活动预览或保存点。规则见 [格式说明](v2-scene-format.md)。

集合列表与原父子树并列，不重排原树。无集合对象维持原可见性。
隐藏集合不会覆盖对象原visible，因此重新显示集合不会强行显示原本隐藏的对象。
集合没有批量变换、多对象选择、颜色标记、渲染开关或独立父变换。
