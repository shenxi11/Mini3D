# 细分修改器（P1-SUBDIV）

选中可编辑对象，在右侧“修改器”页或“编辑 → 细分”添加。卡片支持启用、1/2 级、删除及应用整个求值链；F3/Q 使用相同入口。

## 工作方式

- 使用 Catmull–Clark，要求流形四边网格、无孤立点；边界采用两邻居规则，可支持多个分量。
- 源笼不变且仍可点/边/面选择与编辑。视口实体显示求值结果，新细分点不可当作源组件选中。
- Cube 一级为 26 点/24 面，二级为 98 点/96 面；逐面角 UV/颜色插值保留接缝，按求值共享顶点计算平滑法线。不支持折痕。
- 仅固定 `Mirror → Subdivision`。应用 Mirror 只烘焙镜像并保留后续细分；应用细分烘焙当前最终求值链为源，同时移除两修改器。停用细分时应用仍按当前显示链烘焙，不强行启用它。
- 每次有效参数提交/添加/删除/应用形成一条历史，重复相同参数不增加历史；Undo 恢复完整源、选项与选区。
- 失败候选不替换内容。三角面、五边面（例如单边倒角的端面）、非流形及非法级数明确拒绝；停用只跳过求值，仍校验参数。

## 显示、输出和持久化

源面隐藏通过细分再镜像的来源映射作用于最终三角形。聚焦读取最终求值包围盒；OBJ“修改器结果”输出最终多边形，源导出仍输出原始笼。

外部对象可作为最终细分点的顶点吸附目标。组件移动排除开启细分的整个被编辑对象，因为新点由多个源点驱动，不能假定其只有一个源点身份。

格式3新写 `modifiers[]`，读取兼容旧单 `modifier` Mirror 字段；顺序、重复、未知算子、双字段、布尔/整数类型均严格检查。源与选项保存，求值缓存不保存；旧的阶段程序不保证识别新增修改器字段，使用当前二期源码构建打开新文件。详情见 [格式说明](v2-scene-format.md)。
