# 二期可编辑网格内核

## MESH-01：快照与校验

MESH-01/02 描述独立 CPU 基础；2026-09-12 EDIT-01 已进一步接通场景、历史、GPU 与格式 3，
见 [文档接入说明](v2-scene-format.md)。Tab/组件编辑 UI 仍待后续任务，不能据此宣称 Edit 已可用。

`core/modeling/EditableMesh` 保存多边形真源，不把渲染拆分的顶点当成拓扑顶点：

- 顶点保存 64 位 VertexId 和位置；面保存 FaceId、有序面角环与材质引用。
- 面角保存独立 CornerId、引用的 VertexId、UV、可选硬法线和颜色。共享一个顶点的不同
  面角可以有不同 UV/法线；缺少硬法线表示稍后由派生网格计算，当前不生成 GPU 数据。
- 三种元素 ID 分域唯一且不能为 0，引用只用 ID，不用 vector 下标；重排、复制和循环
  旋转面环不改变身份。ID 分配与撤销后的单调 revision 由后续文档拥有者任务接入，
  当前快照不会自行重新编号，也未实现安装到 Scene 的入口。
- 源边以有序端点对 `EdgeKey` 唯一标识，从多边形环生成。当前没有独立线段/孤立边存储。
- 材质引用为 Core AssetId，0 沿用对象默认材质；资源是否存在必须由后续文档安装验证，
  网格校验器没有 AssetManager 依赖。

原生 `createEditableCube()` 为边长 1、原点居中、Y-up，8 个拓扑点、12 条源边、6 个外侧
CCW 四边面、24 个独立面角。它直接构造多边形，不从一期的 24 个渲染拆点猜测或焊接。

### 校验边界

`validateEditableMesh` 不修改候选，返回首个错误、中文原因，或合法的源边/边界边数量。
允许空快照、孤立顶点、有边界的流形和彼此独立的多个分量；检查：

- ID 唯一/非零、所有面角顶点引用存在；每面至少 3 个不同顶点，不允许环内重复点。
- 位置、UV、颜色有限；显式硬法线有限且非零，不要求已归一化，也不悄悄修改输入。
- 面边端点不能同坐标；面积向量不能为零或相对面尺度过小。面积以局部原点、double
  计算，阈值为 `|面积向量| > 最远点距离² × 1e-10`，避免单位大小改变合法性判断。
- 每条边最多邻接两面，相邻面沿共享边的方向相反。
- 每个顶点只有一个连通面扇；边界顶点有两条边界边。即使边邻接都合法，两个封闭壳
  只共用一个点也会明确拒绝，不能把它当成可安全挤出/环切的网格。

这不是全局自交/自穿透检测，也未证明任意非共面、多孔或自交多边形可以三角化。
后续 MESH-02 和具体算子分别校验自己的形状支持范围；不能把本校验通过等同于所有工具可用。
非法候选返回失败，内存分配异常向调用方传播，输入快照与当前场景均不被修改。

## MESH-02：邻接、三角化与来源映射

### 可重建的源邻接

`buildMeshTopology` 先执行 MESH-01 校验，再从每个面角生成一个有面半边。半边携带
原始 VertexId/FaceId/CornerId，next/previous 构成面环，共享边的两个半边通过 twin 配对。
边界没有虚构的外侧面，twin 为空；孤立顶点的关联列表为空。无向边、顶点和面均有索引。

这些半边下标只在本次构建结果内有效，不能保存到工程或充当用户选中项的身份；源修改后
需要重建。Cube 为 24 个半边、12 个源边，渲染三角化不会把这 12 条增加成 18 条可编辑边。

### 派生三角网格

`deriveMesh` 完整校验后离线生成现有 Core `MeshData`：

- 每个面角生成一个渲染顶点，保持位置、UV、颜色；硬法线归一化后输出，无硬法线则
  使用当前面面积向量计算。源面角不改写，原生 Cube 的逐面颜色/UV/法线与一期工厂逐项一致。
- `vertexSources` 与渲染顶点一一对应，保留64位源 VertexId/CornerId；`triangleSources`
  与每组三角索引一一对应，保存源 FaceId 和材质。GPU 三角索引保持现有32位表示，超容量拒绝。
- 对面使用局部原点/double 面积向量与归一化主轴投影，检查简单环，再执行保留绕序的耳切。
  支持凸面、凹面、反向绕序、连续共线边界点；具有简单投影的非共面面也可生成三角形。
- 投影自交、非相邻接触、相邻边回折重叠、退化或不能找到合法耳的面明确拒绝，原因包含
  FaceId。不提供多孔面或任意空间多边形支持；这也不是网格全局自穿透检测。
- 某一面失败时丢弃本次全部局部候选，不返回前面成功面的部分结果；调用前的源和已安装
  数据不受影响。当前仍没有 Scene 安装/GPU 上传入口，不能把 CPU 派生成功说成界面 Edit 可用。

Cube 派生结果为24个渲染顶点、12个三角形，内部共有18条三角边，但源邻接仍只有12条。
空网格/仅孤立点得到空三角网格，孤立点须由后续编辑叠加层显示，不把它伪装成三角几何。
本阶段是正确性基线，巨大单个多边形的耳切成本与大量四边面不同，性能预算仍由 PERF-01 实测。

专项标签 `[mesh-derivation]` 覆盖半边成环/互反/twin、开边界/孤立点、Cube原外观、来源映射、
凹/反向/连续共线环、3–20角交替凹凸多边形、三角面积/质心、64位ID、缩放/非共面形状与原子失败。
