# 环切并滑移（MODEL-03）

## 两阶段操作

在可编辑对象的 Edit 模式下，鼠标移到源边，按 Blender 风格 `Ctrl+R`。不要求事先选边，
点/边/面域均可启动。菜单“编辑 → 组件变换 → 环切并滑移（单切）”、F3 搜索“环切 / Loop Cut”
和 Q 收藏共用 `mesh.loop_cut`，Registry 当前47项。Legacy 使用菜单/F3/Q，不绑定Ctrl+R。

1. **预览面带**：鼠标命中源边后显示整条候选切线；移动到另一条边可换面带。
   命中半径10逻辑像素，沿用可见/X-Ray源边拾取，不把渲染三角对角线当源边。
   未命中或不支持的面带清除候选并解释原因。左键/Enter固定目标，进入滑移，尚不入历史。
   此阶段右键或Esc取消整个操作。
2. **滑移**：目标带冻结，不随鼠标滑到别处而换带。水平向右增加比例，200逻辑像素为100%，
   0%是原边中点，正方向从命中边较小VertexId端点指向较大端点，并沿面带一致传递。
   数字输入百分数本身，例如`25`表示+25%，`-40`表示-40%，不输入`%`后缀或单位。
   Shift精细倍率0.1且切换连续；Ctrl临时反转10个百分点步进，精确数字不舍入。
3. **确认/取消**：左键/Enter确认当前合法比例；右键把比例设为0并确认居中切线，
   即使当前文字非法也明确改用中心值。Esc仍取消整次操作，恢复环切前的全部内容。
   Enter自动重复不能从预览跳过滑移直接提交。视口外点击、失活、尺寸/相机/文档/选择变化、
   文本或IME预编辑取消；保存途中先取消候选，再保存已确认几何。

比例严格位于(-100%,100%)，禁止端点重叠；因float量化造成端点退化也拒绝。
无效数值原文保留，不能确认上一帧有效结果；退格修复、右键居中或Esc取消均可。
只有单切，滚轮不会悄悄增加切数。不提供Even、Flip、多切或端点焊接选项。
环切当前不是reopenable算子，确认后不提供环切F9；F9仍只支持挤出/内插。
要调整已确认环切可撤销后重做操作，不把Ctrl+Y当作参数调整。

## 支持的面带与几何

从命中边两侧沿四边面的对边查找整条面带。闭合带完整闭合，开放带只允许在两个真实
边界停止。遇到三角/非四边面、同一面被两个方向交叉穿越、滑移方向闭合冲突，整条拒绝，
不截出半圈、不在未分边邻面留下T形连接。

为限定规则面带，当前拒绝被切源边端点连接五条以上边的高价极点/分叉区。
Cube三价角点不会被切线穿过，因此支持原生Cube；不是要求整个网格所有点都是四价。
源网格须满足现有流形、单扇、绕序、引用与三角化校验。候选同样完整校验；凹边界切线
导致子面自交或退化时拒绝，合法局部切线仍可接受。没有全局自相交检测，不能保证与远处
表面或其他对象绝无相交，也不声称任意四边网格都可环切。

每条被切源边仅生成一个共享新顶点，沿原边线性插值；每个面拆成两个四边面，新增一条
切线边。所有原顶点不动。包含原首角的半面保留原FaceId，原面角ID和属性各保留一次，
新面及新角使用新ID；新顶点按源EdgeKey、面/角按源FaceId顺序分配，不依赖数组重排。
UV/颜色和归一化硬法线逐面插值，保持原面材质；共享新顶点不等于焊合各面的UV或法线接缝。
ID空间不足拒绝，没有部分安装。

## 预览、历史与后续编辑

预览仍是组件事务的独立快照；Scene真源、原选区、选择代际、dirty、历史与几何revision
均不改变。覆盖层/N侧栏读取候选网格与候选新边选区，明确“尚未写入文档”；Header仍表示
冻结的原输入选择域，只有确认后才切换为新边域。这样预览不会误改原选区或生成选择历史。

确认一次安装after并形成一条“环切”历史，选中全部新切线边；Undo恢复before及原选择域/
选区，Redo恢复新切线与选区。revision单调前进。新切线可直接用于组件G/R/S，父对象旋转、
负/非均匀缩放不改变局部比例或对象TRS。保存重开保留真实四边拓扑，不存操作会话或历史。

环切、B框选、组件G/R/S、挤出和内插共用排他事务，不并存两份可提交预览。
保持唯一QUndoStack、单线程、Y-up和原GL Context，不重挂视口控件、不新建历史系统。
