# 吸附（SNAP-01）

## 如何操作

1. 在视口头部“吸附·步进”右侧下拉箭头选择“顶点”，点击按钮主体开启吸附。
   同一入口也在“视图 → 吸附类型（G 移动）”；F3 搜索“吸附”可切换类型或开关，支持 Q 收藏。
2. 选择对象，或 Tab 进入编辑模式后选择点、边、面，鼠标置于视口，按 G。
3. 把鼠标靠近目标顶点。命中时出现青绿色方框，HUD 显示目标对象/顶点身份。
4. Enter / 左键确认，一次操作一条撤销；Esc / 右键取消，恢复操作前状态。

对象的源锚点为世界原点；组件为选区去重源顶点的世界质心，开始 G 时冻结。
单点选择的锚点就是该点；多点/边/面统一平移，保持选区内部偏移，不逐点压到目标。
R/S 的变换枢轴偏好不改变 G 的源锚点。

## 步进、Ctrl 与输入优先级

- 默认为“步进”、开关关闭。移动以操作起点为基准，每次 0.5 世界单位，不是绝对网格对齐。
  局部空间按对象世界旋转定义的正交轴换算，不按父级尺度改变步长。
- Ctrl 临时反转：关闭时按住开启，开启时按住关闭；释放恢复，按钮的持久勾选不改变。
  对象手柄在拖动/松开计算时也使用这一异或规则。
- 顶点吸附只用于 G 对象/组件移动。对象手柄、R/S、E/I 沿用原步进规则：
  移动/挤出 0.5、旋转 15°、缩放倍率增量 0.1、内插局部厚度 0.1。
  不提供顶点手柄拖拽、边/面投影或旋转对齐法线。
- 数字输入优先于两种吸附；例如 `G X 1.23` 使用精确的 1.23，不量化为 1.0 或 1.5。
  未完成或非法数字禁止确认，Esc 可取消。
- X/Y/Z 与 Shift+轴约束优先：把“目标减源锚点”的世界位移投影到所选轴/平面。
  轴二按切换全局/局部；约束时最终锚点不一定与目标三维位置重合，方框标的是原目标。
- Shift 仍为分段精细移动；顶点命中使用实际鼠标坐标，不缩小候选阈值。
- 顶点模式无命中时回到同一开始快照计算的非吸附移动，不粘住旧目标、不回到世界原点，
  不暗中切换步进。重新靠近目标即可再次命中。

## 目标和遮挡规则

候选为可见对象的真实顶点，半径 10 **逻辑像素**，随高 DPI 保持相同视觉操作距离。
先按鼠标屏距，等距再按投影深度、对象 ID、顶点 ID/下标确定结果。
不使用包围盒角点替代顶点，不把三角化对角线视作源边。

- 可编辑对象使用稳定源顶点；静态基础体、已加载的导入网格使用渲染顶点。
  导入网格接缝处可能有同位置多顶点，按稳定下标打破平局，不做额外焊接。
- 对象移动：排除正在移动的对象及其子树，既不作为目标，也不参与目标遮挡，
  防止前一帧预览几何遮住目标造成反复命中/丢失。
- 组件移动：只排除本次选区对应的去重源顶点，允许同网格未选点及其他对象顶点。
  目标和遮挡使用已确认的真源几何，预览不反向改变候选；同网格被移开后才露出的点，
  需先确认再开始下一次操作。现阶段不对每一帧临时候选重算遮挡网格。
- 遮挡沿用组件拾取的真实三角深度、背面/材质规则及裁剪规则；隐藏对象/隐藏父级和
  视锥外顶点不参与。X-Ray 是选择偏好，不让吸附穿透遮挡。
- 把同网格点吸到相邻点可能造成退化面：候选仍受原网格校验，非法结果无法确认。
  这不是自动合并/焊接工具；取消不会留下半次几何或历史。

## 生命周期与边界

开关和类型是当前窗口偏好，不标脏、不入撤销、不新增工程字段。
同窗口新建/打开保留，新窗口默认为步进且关闭；几何结果按原工程格式保存。
模式切换取消未确认变换；失焦、失活、视角或文档变化沿用原取消路径，目标框随之清除。
关闭覆盖层仅隐藏目标框，不关闭吸附；HUD 仍提示命中。相机只读预览不能启动变换。

当前使用已有 CPU 三角遮挡路径，尚未完成 PERF-01 的大模型性能预算验收。
本项不包含 Local View、Mirror 或其他后续任务。此前 HTML 手册截至 PIVOT-01，
新增吸附能力与使用边界以本文为增量说明，不把旧截图当成本项截图。
