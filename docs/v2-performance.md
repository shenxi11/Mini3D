## 使用建议

- 基础编辑建议每对象不超过 1 万源点。更大源网格进入 Edit 后，状态栏常驻
  “大网格：点数 · 编辑可能延迟”；关闭 N 侧栏也能看到，退出 Edit 后清除。
- 提示不删除几何、不改变选区、历史或保存点，不静默关闭修改器或降低校验。
- 复杂面、比例编辑、Mirror、Subdivision 和大型选区有额外开销；1 万点不是所有操作的保证。
- 当前源码构建在本机规则网格上已测至 10 万点达标，但不据此取消大网格提示，
  也不将复杂拓扑、全选/大范围变形、点边面全部操作或跨硬件列为同等保证。
- 当前仍是单线程同步编辑。没有本轮新增后台线程、异步任务或 GPU 求值。

### 收尾改动及验证

- 选区只校验请求 ID；投影不先构造全域集合，删除菜单使用非空判断，不复制完整投影。
- 拾取跨三角复用裁剪缓冲，仅为实际点击/框选 ROI 建遮挡桶，保留最终精确可见性和容差。
- 覆盖层复用身份、排列、面角引用完全一致的拓扑；位置、隐藏与选中颜色每次重算，点色复用已算标记。
- 普通组件变换从 Scene 的可信不可变快照增量派生，只重算受影响面的动态几何和耳切；
  公开 EditableMesh 入口仍完整校验（含 no-op），修改器/比例/夹持仍走完整路径。
  同址场景重载切换来源 token，拒绝沿用旧快照，不改变历史恢复语义。
- 工作台点/面总数直接计数；编辑枢轴不再重复求质心，保留双精度中心与活动项语义。

## 实际测量路径与限制

探针在真实 MainWindow / OpenGL 中调用正常编辑器入口，不是独立算法微基准。
固定正视平面四边格、点选择、无修改器且比例编辑关闭；点选为中心附近真实源点，
框选为投影面积约 10% 的矩形，独立计算完整预期 ID 集合并逐项比对。
每次移动预览后取消，校验源哈希、单点选区、历史 count/index/clean 与开始完全一致。

选择时间包含查询、选区发布和同步 UI/覆盖层工作，不代表最终呈现延迟；
预览反馈包含 CPU、队列、上传、合成与 vsync，不是输入设备延迟。
Psapi 峰值包含网格准备、哈希缓冲、Qt、GL 和探针，不是某个阶段的独占峰值。
没有用旧静态球体 FPS 报告替代编辑网格，也未声称边/面选择、复杂拓扑或跨硬件都达标。

## 历史优化轮次与正确性（2026-10-02）

- 可见性查询一次建立屏幕桶，保留精确遮挡与连续边段语义。
- 覆盖层一次索引位置、收集并排序边；保留原绘制顺序、选择颜色和隐藏传播。
- 流形单扇校验复用面角 DSU，派生过程复用逐面 scratch，保留拒绝规则和耳切顺序。
- 普通组件变换由 Scene 内部执行完整变换，再复用刚校验的派生结果；公开接口不接收
  任意“已验证缓存”。无变化仍完整派生，比例/夹持及所有修改器仍按原路径校验。
- 源、拓扑、求值 revision 与 Context 资源生命周期不变；预览不安装源、不写历史。

Release 定向回归：Core 40 用例 / 7254 断言、Editor 18 / 791、拾取 9 / 145；
规模提示与工作台/覆盖层 6 / 124，均通过。两轮独立 Sol/max 静态审查无可操作 P0–P2；
静态审查不代替运行测试。记录在 `out/validation/v2-completion-perf-single-derive-fixed/`
和 `v2-completion-perf-scale-hint/`。新增截图辅助函数的 const 编译错误已修正，首轮失败日志保留。
