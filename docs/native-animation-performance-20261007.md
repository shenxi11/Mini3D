# Mini3D 原生动画性能与内存实测

2026-10-07，Release固定中立夹具三轮均达到本机候选门槛：完整Core求值P95≤5ms，相邻真实换帧及新动画帧换帧P95≤41.7ms。播放没有修改正式动画、基础TRS、文档/历史版本或网格资源。该结果不是全机型、大型模型或长时间耐久保证。

## 固定夹具与方法

102节点中100个有轨：父Empty、Camera、Light及97个可编辑网格；另2个无轨子孙。97×500=48500个可编辑源点，其中非对称旋翼便于观察旋转，一网格实际启用Mirror→Subdivision一级；无轨孙节点另为原生Cube，不把它的内建渲染点混入可编辑源点计数。

300个XYZ整组轨、每轨30键、总9000键，24fps，范围1–697，循环周期29秒。创建、源网格、修改器及定义经正式ViewModel和唯一历史路径安装，不直接篡改内部Scene。

5秒预热后执行30秒×3；每轮独立停止播放、准备完整102节点数值输入，再对checked `evaluateAnimationPose`采样720次。计时包含9000键的定义校验及结果分配，排除输入准备、结果消费/析构、GUI、几何和GPU；不是seek耗时，也不把三轮样本混池。

播放回调仅记录预留容器中的数值戳，停止后统计。每个有效新动画帧要求资源就绪、完整文档/历史/会话/求值身份匹配、同一Context、新frameId和evaluationId且动画时间变化。重复合成不当作新动画帧。

missed ratio为“未出现有效新动画帧的完整墙钟1/24秒槽数÷完整槽数”，尾部不足一槽不进分母；不是以swap次数估算漏帧。相邻间隔分位数不含首尾空白，故另报首末边界。

三轮及预热正确性全部通过：documentRevision=501、historyRevision=500不变；错误身份swap=0；每轮2个重复/旧动画swap不冒充新帧；正式定义、源网格不可变内容、基础TRS、实际编辑相机和矩阵均不变。Pose几何缓存指针复用，topology/geometry/evaluationRevision及真实修改器选项保持，成功editable mesh GPU上传增量均0。该窄计数不代表所有GPU资源上传都已计数，系统不存在独立modifierRevision。

## 失败证据和修正

以下诊断组不能改称通过，原始日志/JSON均保留在同一证据根。

1. `Test-Release-mini3d_editor_tests-232927655.log` / `performance-fe1a9266d2b343109ba7b67bde7d1093`：P95达标，但第1轮文档501→523、历史500不变，1287换帧身份失配，总体失败。没有具体输入事件或原AV栈，不能归咎用户操作或认定动画tick写内容。
2. 专家指出原探针仅进入ViewModel、遗漏预热不变式。改为完整服务入口、预热正确性计入总结果，并加入仅自建窗口的输入隔离/相机记录。
3. `Test-Release-mini3d_editor_tests-233725019.log` / `performance-eac4dbbd13ad48b399542367f9b572c2`：P95及所有不变式通过，但第1轮仅29999.9664ms，少0.0336ms、只有719完整槽，总体仍失败。
4. 测试停止回调按同一单调时钟核剩余ns，提前唤醒补等待；未放宽30秒断言。最终新进程、新证据目录三轮足额通过。

## 复现和证据

性能用例是隐藏Catch测试，不随正常主体构建，也不随默认CTest长跑。需要显式Release构建和筛选；目录先按E盘策略验证路径祖先、实际存储、空间/可写性，设置子进程TEMP/TMP/TMPDIR以及Qt DLL PATH，并给一个全新证据目录。

```powershell
cmake --build E:/Mini3D/out/build/windows-msvc-local --config Release --target mini3d_editor_tests
$env:MINI3D_ANIMATION_PERFORMANCE_EVIDENCE = '<已验证的全新E盘目录>'
# Qt bin须已在当前子进程PATH；性能测试必须使用可见真实窗口。
& 'E:/Mini3D/out/build/windows-msvc-local/tests/Release/mini3d_editor_tests.exe' '[animation-performance]' --reporter compact
```

运行前不要直接复用上面的占位目录；测试拒绝覆盖既有JSON/PNG。独立测试目标与正常主体目标`mini3d_editor`分离。

最终源码：[性能夹具](../tests/AnimationPerformanceTests.cpp)。最终构建`Build-Release-mini3d_editor_tests-233849980.log`，运行`Test-Release-mini3d_editor_tests-234134885.log`：1用例14断言全过、exit0。

本机原始证据根：`E:/Mini3D/out/validation/native-animation-20261007-66e24b/r5-implementation`。最终子目录`performance-42b44eba23534164a830f698323813e9`含完整独立样本/每swap数值戳、各阶段网格与revision、内存、身份及两张真实PNG；主代理已查看两图。正式报告保留口径和数字，原始临时证据不是发布包内容。

本机CPU/GL门槛已达；missed ratio、首尾空白、API延迟和内存没有临时新增或暗中放宽的门槛。更大夹具、30分钟耐久、混合DPI、其它机器及显示器扫描时间不在本次性能验收范围。
