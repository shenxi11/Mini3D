# 饼菜单、着色与重复上一步

## 饼菜单

Blender键位、鼠标在视口时：`Z`打开着色饼菜单，反引号 `` ` `` 打开视图饼菜单。
也可用“视图”菜单或F3搜索同名操作。鼠标点扇区或按条目前的1–9执行；
Esc、中心区或点击外部取消。不抢占文本/输入法，不在变换中截获轴约束键。
弹出前冻结调用上下文，文档/模式/网格/组件选择变化后拒绝原入口并显示原因。

视图菜单提供已实现的前/右/顶/自由方向、正交切换、聚焦所选/全部。
仍是右手Y-up：前沿-Z、右沿-X、顶沿-Y，不称为Blender原生Z-up。
所有条目共用现有Registry与QAction，不另造相机或撤销链。

## 真实着色模式

视口Header“材质/实体/线框”按钮、“视图 → 着色”、F3及Z使用同一状态。

- 材质：现有基础光照、颜色和纹理预览，不是PBR或完整渲染器。
- 实体Solid：中性表面色，不显示纹理和逐顶点色。
- 线框Wireframe：真实GPU网格线框；包含渲染三角化对角线，这些线不是可选源边。

没有Rendered或假着色模式。X-Ray控制组件穿透选择/覆盖层，和线框着色独立，
切换显示不会修改几何、选择、对象材质、历史或工程文件。显示模式只保留本窗口会话，
GL Context重建后仍回放当前模式；不是新的保存字段。

## Repeat与F9不同

“编辑 → 重复上一步（新操作）”、F3的Repeat Last、Blender键位`Shift+R`：
目前只重复历史末端已确认的挤出、内插或倒角，复用其最新参数，
在**当前**可编辑对象、当前源和当前选区上重新执行并新增一条历史。
原操作的命令、before和目标不修改。无有效末端配方、选择不适用或变换未结束时禁用。
当前选区可以和原操作不同；另一个已可编辑对象也可作为目标。

F9是原操作参数调整：从原before重算并替换该命令after，不添加一条历史。
例如内插确认后Repeat会再生成一圈；F9只改变原来那一圈厚度。
倒角确认后默认选中新面，需要先选一个可支持的源边再Repeat。
重复参数在新面/边上可能超限，此时整个新尝试取消，原几何、选区和保存点保持不变。

Redo仍只回放被Undo的历史。Repeat不是Redo，不重放旧对象/旧选区的F9闭包。
当前不支持重复环切、组件/对象GRS、删除/补面、集合或修改器操作；
非可重开操作位于历史末端时没有Repeat配方，不会猜测参数或越过历史。
重新打开工程不会恢复Undo或Repeat配方。长按上述菜单/Repeat快捷键不会连续执行。
