# Blender 参考布局与视图导航（2026-10-05）

本轮依据下载目录的“参考图1.png”和“参考图2.png”调整现有 Qt/OpenGL 工作台。两张原图已经实际打开查看；此前 Library 附件未落地的阻碍由用户提供本机文件解决。

## 参考与适配范围

- 图1为 2048×1115：主区宽度约 82%，右栏约 18%；右栏场景区约占高度 18.5%，属性区约 81.5%；主区底部区域约占高度 7%。这些比例按各自分区衡量，不能等同于旧任务的“GL 视口占总工作区约 80%”。
- 顶部菜单、工作区和视图标题采用较低的行高；左工具栏位于视窗内部。右上导航按图2的彩色正向轴、反向圆点与圆形背景组织。
- 底部使用当前控制台和操作输出，不增加动画时间轴功能。相机和建模仍保持项目已有的 Y 轴朝上约定；轴标签依据真实相机投影显示。
- 已有无限地面网格、建模功能、存档协议及工作区偏好保持兼容。本轮修改以前的未提交源码有独立字节备份，回滚不采用 HEAD 全量还原。

## 使用方式

没有工作区布局记录时，首次显示按当前窗口应用参考比例。已有 `workbench/v2` 布局仍优先恢复，不清空用户设置。需要切换时使用“视图 → 应用参考布局”，或视口顶部“面板 → 应用参考布局”；仅调整当前工作区，其他工作区保持各自设置。

右上方彩色导航轴与真实相机同步：点击 X/Y/Z 方向圆点切换六个轴向视图；在已经对齐的轴上再次点击会转到相反方向。拖动圆形轴区旋转视图，下方四个按钮依次用于缩放、平移、相机预览、透视/正交切换。缩放和平移按钮支持拖动；缩放按钮也支持滚轮。Esc 结束当前导航手势，已发生的观察移动保留，不产生建模历史。

导航开始时取消尚未确认的建模变换、框选或环切预览，避免把导航点击当作模型操作确认。相机预览使用已有真实场景相机；预览期间轴向旋转和投影按钮不可用，点击相机按钮返回此前编辑观察视角。

左工具条悬浮在真实 GL 视口内，悬停可查看操作名称与快捷键。顶部保留模式、材质、视图、点/边/面、穿透及覆盖层入口；完整变换设置默认折叠，可从“变换设置”展开。右侧“场景/集合”标签切换已有对象树与集合操作，较小区域支持滚动；属性字段与撤销重做继续复用已有业务入口。底部保持实际控制台输出。

应用参考布局之后，普通窗口缩放仍保留用户调整过的区域尺寸，不强制反复重置为参考比例。若需要在新的窗口大小重新按比例排布，再执行一次“应用参考布局”。
