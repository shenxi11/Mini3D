# 原生动画 R3 接口与施工边界

2026-10-07；依赖已关闭的 R1/R2。本文是施工合同，不是已通过验收的产品说明。

## 1. 专项审计结论

Astra 只读确认：仅添加显示矩阵或在 `recordApiCommit` 之后重新求值不足以保证一致性。必须同时处理候选命令回放、版本前旧通知和导航先改相机的问题。

统一顺序为：候选数值/几何/设备验证及包装分配 → 最终来源/提交守卫 → 隔离消费者 → 内容或历史安装 → 正式版本推进 → 绑定已准备包装 → 有效选区/结构/内容通知。新编辑求值失败不入历史；历史当前时间失败或旧命令没有适配器，先使旧姿态不可消费，再恢复历史、返回 Base 并报告诊断。

准备前必须冻结统一来源凭据，包括文档、会话、已安装姿态、选择、隐藏掩码与观察/交互来源；任何可重入视图提供者或提交守卫返回后，先复核凭据，再使用草稿/候选或发布。回调中取消草稿、切选区、隐藏对象、改名或 seek 均不得让旧计算冒用新来源。旧几何历史也必须延后完成通知，开始/reset 信号保留原职责。

## 2. 显示快照

`InstalledPose` 包含应用实例、文档、内容来源版本、evaluationId、frame、mode，以及不可变数值和几何快照。绘制入口将完整文档 stamp 与姿态一起冻结；同步尺寸/视觉通知之后再次复核来源和会话包装，变化则拒绝该次消费，不能将新文档 stamp 配旧姿态，也不能默默画 Base。真实抓图后须核对当前文档、观察版本、mode 与完整姿态身份。

几何快照只在准备阶段扫描点，持有可编辑内容及 AssetManager 所有权，保留每个节点的父关系、局部盒、有效可见性、完整元素隐藏掩码、真实网格 evaluationRevision 和设备参数。预览绘制与拾取只消费冻结掩码，不读取可变 Renderer 会话值；缓存比较完整掩码而非仅比较数量。tick 复用局部盒，只检查实际 float 八角与设备 view/projection。复制通过固定 ID 映射复用局部几何；删除历史持有恢复所需的不可变几何条目。

子树安装会分配新的网格 revision。仅未发布且独占的候选 geometry 可在安装后、Pose 发布前，用实际 mesh record 无分配绑定标量 revision；不能修改已安装、历史或共享包。验收须比较 entry 与实际 record 的 revision，并通过真实窗口证明复制及删除 Undo 后 Base/Preview 不重复上传。

Renderer 与 RayCaster 的既有基础查询保持默认行为，末尾可选 `InstalledPose` 参数用于显式动画消费者。显示、拾取、选框、focus、Camera、Light、手柄及真实帧 stamp 共用冻结的包装。动画路径不递归遍历深层树，不每帧扫描源点或上传未变几何。

## 3. 编辑器会话与界面

SceneViewModel 独占 Base / PreviewPaused / Playing / PoseDraft，公开控制、当前帧、会话版本和已安装姿态；时间轴只发送意图。时钟使用单调 elapsed，Timer 只唤醒；tick 不推进正式版本或会话版本。隐藏/终点/故障停止属于真实状态变更，须推进会话版本。

pause 准入后一定停钟；异常时保留有效 Paused 包装，或明确故障退出 Base 并清姿态，不能留下 Paused 模式与 Playing 包装身份不一致的不可消费状态。

历史恢复的视图读取失败使用局部异常类别保留跨准备栈的来源。观测失败后不再调用该Provider，但完整非视图凭据仍须在真实提交守卫前后核对；守卫拒绝、自身异常或来源重入不能降为默认许可。普通候选/几何分配失败不等同Provider失败。

GUI在Base/Paused的实体相机预览中保留既有相机/灯光参数编辑许可，API仍保留camera_preview Busy。两入口共用私有候选与提交主体，主体在取消旧变换的同步回调之后再核Playing/Draft/提交中准入；不通过等待重绘或放宽公共API守卫修复GUI回归。

中文时间轴提供预览、播放/暂停、子帧定位、范围/fps、循环、通道录键、键表与草稿入口；默认收起，可从“视图 → 动画时间轴”打开，以保留已有建模布局。普通属性面板仍显示基础 TRS。草稿 XYZ 面板以冻结 mask 限制许可，旋转保存连续 Euler 原值；确认单历史、取消不写源。受限 G/R/S 在此基础上接入，不复用写真源的旧预览；鼠标 Enter 同步起点，重复 Esc 不跨越“手势→完整草稿”取消边界。

导航从 EditorCamera 副本生成候选，ViewModel 联合准备姿态与设备视图后，通过同步 installView 回调安装真实观察相机，再推进正式版本并发布。Playing 导航保留时钟基线；Draft 在真实相机修改前拒绝。

## 4. 并行所有权

- renderer 实施代理（请求 Sol/max）：InstalledPose、Renderer、RayCaster 及其独立测试。
- session 实施代理（请求 Sol/max）：SceneViewModel、SceneAnimationEditing/Session、EditCommand/TransformEntityCommand/SubtreeCommand 与会话测试。
- 主代理：ViewportWidget、MainWindow、时间轴、受限快捷键、CMake、正式文档、日志与串行构建整合。

共享文件不得同时修改；Core 新候选访问器由主代理按实际需要单点添加。每阶段实现后仍需独立 Sol 与 Astra 复核。工具缺少 provider 生效回执，以上是请求配置，实际路由未独立验证。

## 5. 验收门禁

检查父动画对无轨子孙的显示/拾取/设备一致性、不同文档同版本拒绝旧姿态、seek 后 Undo 在当前时间重新准备、回放数值失败恢复历史并清预览、纯重命名共享数值且重绑身份、导航失败保持旧相机/版本/姿态、tick 无脏与 session 变化合同。真实 Qt/GL 绘制、DPI、草稿焦点、资源复用和性能须另外运行，不把静态接口成立称为 R3 通过。
